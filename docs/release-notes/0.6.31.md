## Beta: please read
- **This is a beta.** Expect rough edges, and keep backups of anything important (Settings → Data & backups).
- **The installer and the app aren't code-signed yet.** Windows SmartScreen may say "Windows protected your PC": choose
  **More info → Run anyway** only if the SHA-256 of your download matches the one published with the release. The
  update information inside the app *is* signed, twice (ECDSA P-256 and post-quantum ML-DSA-65), and the app refuses an
  update unless both signatures match.
- **Testers are very welcome.** Many integrations are built against the vendors' published APIs but haven't yet been run
  against a live account, because I don't have access to those services. If you use any of them, I'd love to hear
  whether it works:
  - Microsoft 365 admin (Intune, Defender, Entra), Windows 365 Cloud PCs and Microsoft Teams;
  - Bitwarden (Password Manager and Secrets Manager, cloud and self-hosted / Vaultwarden);
  - UniFi (Network on a console or through the Cloud Connector, and Site Manager);
  - BeyondTrust Privileged Remote Access, Pingdom, Grafana / SIEM links, Elasticsearch and Loki log sinks;
  - Contabo, Hetzner Cloud, Azure and Google Cloud;
  - VMware vCenter, Hyper-V, Proxmox, Unraid, Docker, Puppet, WSL and serial consoles.
- **Bugs and feature requests:** please use the forms on darkciphersystems.com (Report a bug, and Feature requests →
  ServerManagement).

## New
- **The hosts panel, beside every tab.** The HOSTS panel (your folders, hosts, ★ Favourites, shared libraries, the
  filter, ＋ Host and ＋ Folder) now sits on the left of the main window, next to whatever tab is in front: a terminal,
  a remote desktop, Files or Settings.
  - **📌 Pinned** (the default) gives it its own column; drag its edge to resize it.
  - **📍 Auto-collapse** folds it to a slim **Hosts** strip. Point at the strip (or click it, or drag hosts onto it) and
    the panel opens beside the tabs, then folds back when you move away. It never covers a terminal or a remote desktop.
  - The Hosts tab is now just your host list. Closing it keeps the panel.
- **Stacked tab groups.** A tab group can fold into a single tab, so a busy tab bar takes less room:
  - Click the group's name on its tab, or right-click a tab → Tab group → **Stack into one tab**.
  - The stack shows the tab you used last, and its name says how many it holds (for example **web 4 ▾**).
  - **Click the name** for a list of the group's tabs and pick one, or **turn the mouse wheel** over it to step through
    them. Ctrl+Tab and "switch to the open tab" reach them too.
  - **Spread out** (in that list or the tab menu) shows them all again. Stacked groups come back stacked with saved
    sessions and workspaces.

## Changed
- **One tab bar.** Sessions you open from Hosts no longer open as tabs inside the Hosts tab: everything opens in the
  main tab bar. Reopened or reconnected sessions can't end up in a different place any more. The "Open sessions from
  Hosts" setting and its Group Policy (HostsOpenIn) are retired; a policy that still sets it is reported as no longer
  used. The HostsDock policy (pinned / auto) now sets the hosts panel.
