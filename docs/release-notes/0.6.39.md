# ServerManagement 0.6.39 (2026-11-09) – DarkCipher Systems

**Public beta.** Built by an IT engineer, for engineers. Free and open source (MIT). Post-quantum ready.

## Beta: please read
- **This is a beta.** Expect rough edges, and keep backups of anything important (Settings → Data & backups).
- **The installer and the app aren't code-signed yet.** Windows SmartScreen may say "Windows protected your PC": choose
  **More info → Run anyway** only if the SHA-256 of your download matches the one published with the release. The
  update information inside the app *is* signed, twice (ECDSA P-256 and post-quantum ML-DSA-65), and the app refuses an
  update unless both signatures match.
- **Testers are very welcome**, especially for CipherChat calls and live session sharing against your own CipherChat
  server, and Windows management against remote computers.
- **Bugs and feature requests:** please use the forms on darkciphersystems.com (Report a bug, and Feature requests →
  ServerManagement).

## New
- **Windows management, built in.** Sidebar → WINDOWS → 🪟 Windows management (Ctrl+Alt+W) is an MMC-style console for
  this PC or another Windows computer: overview, services (start, stop, restart, startup type), processes, startup
  items, drivers, updates, the System / Application / Setup / Security event logs (errors-and-warnings filter), disks,
  volumes, shares, local users and groups, network adapters and connections, and scheduled tasks (run, enable, disable).
  It talks WMI directly with packet privacy; another computer uses a saved host's credential, which never appears on a
  command line. A **WMI console** runs WQL and the wmic commands you know (`os get caption,version`,
  `service where state="running" get name`, `logicaldisk list brief`, `path …`, `/namespace:…`) and only ever reads:
  `call`, `set`, `delete`, `/node:` and `/user:` are refused with the reason. The classic consoles (Computer Management,
  Event Viewer, Services, …) open with the chosen computer. Every change asks first and is in the audit log.
  Settings → Windows management has the switch and the rules, and Group Policy controls all of it (`WinToolsFeatures`,
  `WinToolsAllowChanges`, `WinToolsAllowRemote`, `WinToolsAllowConsole`, `WinToolsAllowSecurityLog`,
  `WinToolsEventLimit`).
- **Settings → CipherChat.** CipherChat has its own Settings page: the on/off switch (admin-protected, Group Policy
  `ChatFeatures`), the rules on this PC (every chat policy, shown locked when your organisation sets it), notifications
  and locking, and your chat accounts (lock one, forget this PC, open Chats).
- **Share a live session in a chat.** Right-click a terminal, RDP or VNC tab → **📡 Share live in a chat…**: the tab gets
  its own window and a call starts in the room you pick, sharing exactly that window (no screen picker, nothing else can
  be shown). Others watch and help in the call; hang up and the tab docks back. Group Policy `ChatAllowSessionShare`.
- **Chat notifications and an idle lock.** A new message shows a Windows notification unless you're already reading that
  room (a burn-after-reading message never shows its text there); the call ringtone can be turned off; every chat can
  lock itself after a number of minutes without input (`ChatNotify`, `ChatRingSound`, `ChatAutoLockMinutes`).
- **Module add-ons.** An add-on can now be a module of the app, with its own screens, settings, Group Policies and help,
  but only when DarkCipher Systems signed it with the release keys (ECDSA and ML-DSA). Every file is checked against
  that signature at install and again at every start, and a changed one is switched off. Group Policy
  `AddonAllowModules` = 0 turns them all off.

## Changed
- **The stream manager for Twitch left the app.** All of its code, settings, policies and help are now in its own
  module add-on (Stream manager for Twitch 0.2.1), so the app carries none of it. Settings you already had move into
  the add-on the first time it loads; the policies keep their names. The add-on will be published separately once it
  has been tested against Twitch. Group Policy `StreamFeatures` is gone; block the add-on with `AddonBlockedIds` or
  `AddonAllowModules` instead.
- **Stream manager add-on 0.2.1: a live player in the preview tile.** ▶ Watch live shows Twitch's player, muted,
  only while you watch; it stops when you go offline or hide the tile. Group Policy `StreamPlayer` = 0 turns it off.
