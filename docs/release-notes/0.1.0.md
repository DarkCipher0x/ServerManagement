# DarkCipher ServerManagement 0.1.0 (2026-10-17 to 2026-10-18)

The first builds: roadmap #1–#16 and spec sections §48, §53 and §55 (sessions 3–27), all under version 0.1.0 before the one-version-per-build rule.

- **Encrypted store:** AES-256-GCM under DPAPI and/or a master password, with app lock, TOTP 2FA and sandbox mode; snapshots, verified restore and start-up recovery.
- **Sessions:** SSH terminals (xterm.js), local PowerShell / cmd / WSL (ConPTY), serial and USB-serial consoles, embedded Remote Desktop with mstsc fallback; auto-reconnect; tabs, split panes, pop-outs; workspace restore after a crash.
- **Files:** SFTP, SCP fallback, the two-pane File commander, a transfer queue with verify / resume / retry, folder compare and sync.
- **Servers:** the manage view (overview, services, processes, logs, packages, Docker, network, firewall, users, cron), tunnels, snippets and multi-host runs, known hosts.
- **Cloud and infrastructure:** Vultr API v2 coverage; Docker, Proxmox VE and Unraid providers, read-only until allowed.
- **Notes, incidents and reports**, with an offline search index.
- **AI engineer:** local-first engines, a "data being sent" preview, secret masking, approval for every change; PDF and vision-gated screenshot analysis.
- **Privacy & network view,** paste safety, offline / air-gapped mode (§53), environment labels with production safeguards (§55), the engineering dashboard (§48).
- **Local API + OBS broadcast; sandboxed add-ons with an SDK;** an updater (switched off until releases are signed).
- **UI text size and window scaling;** fuzzing, endurance and leak testing.
