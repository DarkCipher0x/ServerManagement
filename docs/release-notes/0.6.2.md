# ServerManagement 0.6.2 (2026-10-21) – DarkCipher Systems

The Hosts folder pane pins or auto-collapses inside the Hosts page, and updates can be checked from a private GitHub
repository with your own access token.

## Changed
- **The folder pane pins or auto-collapses inside the Hosts page**, and nothing docks beside your sessions any more
  (0.5.8–0.6.1's host pane is gone). The Hosts page is as it was, and the folder pane on its left now has a push-pin:
  - **📌 Pinned** (the default): open beside the hosts, as before; drag its edge to resize.
  - **📍 Auto-collapse**: it folds to a narrow "FOLDERS" strip inside the Hosts page, giving the host list the room.
    Point at the strip (or click it, or drag hosts onto it) and the folders slide out over the list; they slide back
    when you move away or click into the list.

  Also in Hosts → More ▾ and Settings → Navigation → Sidebar → Hosts folder pane, and as the Group Policy `HostsDock`
  (now `pinned` / `auto`; the old `tab` value reads as pinned).

## Added
- **A GitHub access token for updates from a private repository** (Settings → Updates, under "Updates from: GitHub
  releases"). With your own read-only token the app reads the latest release through GitHub's API, so the update check
  can be tested before the repository goes public. Leave it empty once the repository is public.

## Security
- The token is yours (a fine-grained token with read-only Contents access to this repository only), stored encrypted
  with your settings, never written to the registry or a policy, and removed from backups made without secrets. It is
  sent only to api.github.com: the download host GitHub redirects to never sees it. An update is still installed only
  when the DarkCipher release key's signature verifies, and the signed version must match the release's tag.
- Removing the dock beside the sessions removes code; no change to storage or encryption.
