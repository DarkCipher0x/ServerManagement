# ServerManagement 0.6.37 (2026-11-08) – DarkCipher Systems

**Public beta.** Built by an IT engineer, for engineers. Free and open source (MIT). Post-quantum ready.

## A note from the developer
ServerManagement is one of my favourite projects yet, and I'm excited to finally share it. I'm an IT infrastructure
engineer, and I designed it around the job: one encrypted workstation for your servers, network, hypervisors and
clouds, without licences or per-seat pricing. This is just the start. I'll keep adding as many systems as I can, and
all of it stays free and open source.

## Beta: please read
- **This is a beta.** Expect rough edges, and keep backups of anything important (Settings → Data & backups).
- **The installer and the app aren't code-signed yet.** Windows SmartScreen may say "Windows protected your PC": choose
  **More info → Run anyway** only if the SHA-256 of your download matches the one published with the release. The
  update information inside the app *is* signed, twice (ECDSA P-256 and post-quantum ML-DSA-65), and the app refuses an
  update unless both signatures match.
- **Testers are very welcome.** Many integrations are built against the vendors' published APIs but haven't yet been run
  against a live account, because I don't have access to those services. If you use any of them, I'd love to hear
  whether it works:
  - Microsoft 365 admin (Intune, Defender, Entra), Windows 365 Cloud PCs and Microsoft Teams;
  - the OpenAI API engine (new in 0.6.34: built to OpenAI's published Responses API, tested against a local stand-in);
  - the new Redfish (HPE iLO, Supermicro, Dell iDRAC, Lenovo XCC), HPE GreenLake and Sophos Central providers (0.6.34:
    built to the vendors' published APIs, tested against stand-ins);
  - Bitwarden (Password Manager and Secrets Manager, cloud and self-hosted / Vaultwarden);
  - UniFi (Network on a console or through the Cloud Connector, and Site Manager);
  - BeyondTrust Privileged Remote Access, Pingdom, Grafana / SIEM links, Elasticsearch and Loki log sinks;
  - Contabo, Hetzner Cloud, Azure and Google Cloud;
  - VMware vCenter, Hyper-V, Proxmox, Unraid, Docker, Puppet, WSL and serial consoles.
- **Bugs and feature requests:** please use the forms on darkciphersystems.com (Report a bug, and Feature requests →
  ServerManagement).

## New
- **CipherChat inside the app (preview, off by default).** DarkCipher's post-quantum chat, built on CipherChat's own
  code, with native screens: turn it on in **Settings → Security & privacy → CipherChat** (an administrator's switch,
  behind UAC). Pair this PC as a device with a pairing code (or sign in with password and authenticator code), then open
  rooms as tabs, pin one beside any tab (**Ctrl+Shift+J**), and use **Send to a chat…** from terminals, the file
  commander, reports, snippets and screenshots: the room opens with the material ready, and nothing is sent until you
  press Send. Server owners get a **Chat server admin** pane with its own sign-in that is never remembered. Only the
  device pairing is stored, encrypted; the app lock and quitting wipe every chat key. Off, none of the chat code is even
  loaded. Group Policy covers it all (`ChatFeatures`, `ChatAdmin`, `ChatAllowedServers`, `ChatAllowFiles`,
  `ChatMaxFileMB`, `ChatAllowCalls`, `ChatShareFromScreens`, `ChatToastPreviews`). **Not yet:** calls. It hasn't been
  run against a live CipherChat server yet, so please tell me how it works with yours.
- **Stream manager for Twitch (needs its add-on, not yet released).** The app now contains a stream manager that a
  separate "Stream manager for Twitch" add-on switches on: a dashboard, chat, an activity feed, stream info, clips,
  markers and ads with keys that also work while you're in a game, and Streamer.bot on your streaming PC. Without the
  add-on nothing of it loads or shows. The add-on will be published separately once it has been tested against Twitch.
- **History is yours to keep or not, and off by default.** One switch in **Settings → Security & privacy → History**
  covers everything the app remembers about what you did: quick connect's recent lines, the command palette's recent
  picks, Toolbox runs, finished transfers, when each host was last connected and each portal last opened, and the
  pages visited in portal tabs. **Off (the default), nothing is remembered.** On, it is kept encrypted like everything
  else and can clear itself **when the app closes** or **every 1, 7 or 30 days**.
  - **Clear it anywhere:** the quick connect bar's list now ends with **Clear recent** (and **Shift+Del** forgets the
    selected line), the History card has a **Clear** button for each kind with its count and **Clear all history…**,
    and the command palette has **Clear all history…** (give it a key in Settings → Keyboard if you like).
  - Pinned lines, saved hosts and portals, notes, reports, snippets and the audit log are not history and always stay.
    Sign-ins in portal tabs stay too: only their page and download history is cleared.
  - Clearing is written to the audit log (which kinds and how many, never the entries).
  - **For administrators:** Group Policy can set `HistorySave` and `HistoryAutoClear` (`never`, `exit`, `1`, `7`, `30`).
  - **Upgrading:** because history is now off by default, the first start of 0.6.37 clears the recents and "last
    connected" times earlier versions kept. Turn History on first thing if you want to keep collecting them.
- **Full keyboard control, and every shortcut can be changed: Settings → Keyboard** (Ctrl+Shift+/). Every command the
  app has, with its keys, grouped and searchable by name or by key. **Change…** and press the new keys (Esc cancels):
  the page says first whether they're free, belong to another command (using them moves them) or would go to the remote
  program in a terminal. Add a second or third key, remove them, put one command's defaults back, or reset everything;
  **Copy the list** gives you a table to paste into a note. Keys that must keep their meaning (Tab, Esc, Alt+F4,
  Shift+F10, copy / paste / undo, the terminal's Ctrl+Shift+C / V) can't be taken, so a change can never lock you out.
  Your shortcuts are stored encrypted with your settings, written to the audit log when changed, and travel with
  Settings → Import & export.
- **New commands:** go to tab 1–8 (Ctrl+1 … Ctrl+8) and the last tab (Ctrl+9), move the tab left / right (Ctrl+Shift+PgUp / PgDn), open the tab's menu (Ctrl+Shift+F10),
  reconnect the terminal (Ctrl+Shift+R), move to the sidebar (Ctrl+Shift+E; ↑ ↓ Home End move, Enter opens, Esc goes back
  to the tab), Settings (Ctrl+,), "Go to …" for every page, and close other tabs, close all, rename and move to the next
  pane (no key until you give them one). Every command is also in the command palette (Ctrl+Shift+P), with its keys.
- **Keyboard focus you can see:** a ring in your accent colour instead of Windows' faint dotted line.
- **Terminals keep their keys, as before:** in a terminal, VNC or Remote Desktop session only Ctrl+Shift, Ctrl+Alt,
  Ctrl+Tab and Ctrl+F-key shortcuts are taken, and plain Ctrl+letter, Alt+letter and F-keys go to the remote program.
  The page marks the keys that don't work there.
- **The screens' keys are in the list too:** portal tabs (F5, Ctrl+L, Alt+← / →), notes (Ctrl+S, Ctrl+Shift+T), the text
  and hex editors (Ctrl+S, Ctrl+F, Ctrl+H, Ctrl+G, F3 / Shift+F3, Ctrl+Alt+V), search on a page (Ctrl+F) and the file
  browser's refresh (F5). The file commander keeps Midnight Commander's keys and the editor's Vim mode keeps Vim's.
- **Screens keep their own keys:** while the file commander's list has the keyboard, F6 moves files again (next pane is
  Ctrl+F6 there), F1 opens its help and Ctrl+Shift+S its filter. While you type in a Docs page, Ctrl+B is bold and
  Ctrl+K a link again (the sidebar stays on Ctrl+Shift+B and quick connect on Ctrl+Shift+K).
- **For administrators:** Group Policy can set the shortcuts (`KeyBindings`, one `command.id=keys` line each; the ids
  are on the Keyboard page) or keep the defaults (`KeyBindingsAllowChange` = 0). The page then shows the lock.
