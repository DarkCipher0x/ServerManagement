# DarkCipher ServerManagement 0.1.6 (2026-10-18)

## Foundry Local set-up in four numbered steps
- **Settings → AI engine → Foundry Local** now shows the set-up as buttons, in order:
  1. **Install Foundry Local**: checks for it; if it's missing, asks, then installs it with winget.
  2. **Start Foundry Local**: starts the service and keeps it running.
  3. **Load the model**: loads the selected model; the first time downloads it.
  4. **Test**: asks the model to reply "OK" and shows how long it took.
- **Each step shows ✓ or ✕ with what happened.** When you open Settings, the steps already done are ticked.
- **Model buttons:** pick the model before step 3: Best for this PC, NPU: phi-4-mini, CPU: phi-4-mini, CPU: lightweight (0.5B). "Copy the commands" copies the whole sequence for a terminal.

## The default model is the best one for your PC
- **The engine is still Foundry Local (never Ollama).** The model now follows the hardware:
  - with an NPU: phi-4-mini on the NPU;
  - no NPU, 16 GB RAM or more: phi-4-mini on the CPU;
  - no NPU, 8–15 GB: Qwen2.5 1.5B on the CPU;
  - less than 8 GB: the lightweight Qwen2.5 0.5B.
- **Applies once after updating,** and only where the model is still one the app chose. A model or engine you picked is kept.
- **"Detect hardware" recommends the same model.** With a strong graphics card it also mentions Ollama as an option.

## Install folder
- **The app now installs to `C:\Program Files\DarkCipher Systems\ServerManagement`.** Earlier versions used `…\Server Management`.
- **Upgrading moves it:** the old folder is removed and the new one used. Your data is not in the program folder and is unchanged. A taskbar pin you made by hand may need re-pinning.

## Documentation
- **In-app help:** rewritten articles "AI engines", "Set up Foundry Local, step by step" (with troubleshooting) and "Which model should I use?".
- **PDF guide:** a new chapter, "AI: engines, set-up and privacy". It covers what each AI feature can do, the engines, the hardware default, exactly what the app runs for each set-up step, how it finds the service and picks model IDs, privacy and offline mode, and the related settings.
- **The guide now includes every release note and architecture decision up to this version.**

## Before you rely on it
- **Verified by the automated self-test:** a watched run with no window. It covers the default for each hardware case, the 0.1.5 → 0.1.6 change, the four steps and their status lines against a fake Foundry Local and a real local test server, and a rendered picture of the steps.
- **Not yet verified:** the new install folder needs a real install or upgrade by hand. Foundry Local is still untested on a real NPU from this build.
- **Not code-signed:** SmartScreen shows "unknown publisher", and in-app updates stay switched off.
