# DarkCipher ServerManagement 0.1.2 (2026-10-18)

## New: Contabo as a cloud provider
- **Contabo accounts** (Settings → Contabo accounts): add with the Client ID, Client Secret, API user and API password from Contabo's Customer Control Panel → API.
  - Test shows the instance count.
  - Several accounts are supported; you can rename one, replace its credentials, disable it or remove it.
  - The credentials are stored only in the encrypted settings and never shown again.
- **CONTABO in the sidebar:**
  - **Instances:** start, graceful shutdown, restart, hard stop, rescue, reset password, reinstall, snapshots (with rollback), upgrade options (read-only), rename, order a new server, cancel a contract;
  - **Images:** standard and custom images from a URL;
  - **Secrets:** SSH keys and passwords, including uploading the public half of a vault key;
  - **Private networks, firewalls, DNS zones and records;**
  - **Reference:** data centers, standard images and the action history.
- **Buttons follow the server's state,** for example Start only on a stopped server; hover a greyed button for the reason. After an action, the screen watches the server until it reaches the new state.
- **Safety for real money and real servers:**
  - **Ordering:** a new server is a billed order and asks first; an order is never re-sent automatically. If Contabo answers slowly, you're told to refresh before trying again.
  - **Destructive actions:** reinstall, rollback and contract cancellation ask you to type the name.
  - **Production hosts:** a server whose host is labelled PRODUCTION follows the production rules.
- **Hosts and the rest of the app:**
  - **Import from Contabo:** follows changed IP addresses and lists hosts whose server no longer exists.
  - **Manage:** offers a Contabo power cycle.
  - **Dashboard:** the "Cloud servers" card covers both providers; Contabo checks are opt-in under Checks ▾.
  - **AI operator:** can list and power Contabo servers, after your approval.
  - **Privacy view and offline mode:** both cover Contabo.
- **What Contabo's API can't do, so the app doesn't offer it:** delete (cancel the contract instead), resize, and a web console.

## Improved for every cloud provider (Vultr too)
- **One cloud layer for both providers:** the same screens, forms, menus, account handling and error messages.
- **Vultr:**
  - **Buttons follow the server's state:** Start, Reboot and Halt now do this, with the same status watch after an action.
  - **Accounts can be disabled.**
- **Safer requests:**
  - every request has a finite timeout;
  - only safe requests are retried (reads, and rate-limited changes that weren't processed);
  - orders are never retried;
  - errors are plain sentences with the provider's request id, and never contain credentials.
- **Account changes in Settings reload the provider's open screens.**

## Fixes
- **Self-test reliability:** the Telnet test's fake device could swallow typed input. The cause (an abandoned socket read) is fixed.

## Before you rely on it
- **Verified by the automated self-test** (165 checks, no failures, several runs), against an in-process fake Contabo API built from Contabo's official specification.
- **Not yet verified against your real Contabo account:** the app has no real credentials to test with. Try the read-only screens and a start/stop on a test server first (OUTSTANDING.md has a checklist), and order or cancel only deliberately.
- **Not code-signed:** SmartScreen shows "unknown publisher", and in-app updates stay switched off.
