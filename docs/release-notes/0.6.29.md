**Public beta.** Built by an IT engineer, for engineers. Free and open source (MIT). Post-quantum ready.

## Beta: please read
- **This is a beta.** Expect rough edges, and keep backups of anything important (Settings → Data & backups).
- **The installer and the app aren't code-signed yet.** Windows SmartScreen may say "Windows protected your PC": choose
  **More info → Run anyway** only if the SHA-256 of your download matches the one published with the release. The
  update information inside the app *is* signed, twice (ECDSA P-256 and post-quantum ML-DSA-65), and the app refuses an
  update unless both signatures match.
- **Testers are very welcome.** Many integrations are built against the vendors' published APIs but haven't yet been run
  against a live account, because I don't have access to those services. If you use any of them, I'd love to hear
  whether it works:
  - Microsoft 365 admin (Intune, Defender, Entra), Windows 365 Cloud PCs and Microsoft Teams;
  - Bitwarden (Password Manager and Secrets Manager, cloud and self-hosted / Vaultwarden);
  - UniFi (Network on a console or through the Cloud Connector, and Site Manager);
  - BeyondTrust Privileged Remote Access, Pingdom, Grafana / SIEM links, Elasticsearch and Loki log sinks;
  - Contabo, Hetzner Cloud, Azure and Google Cloud;
  - VMware vCenter, Hyper-V, Proxmox, Unraid, Docker, Puppet, WSL and serial consoles.
- **Bugs and feature requests:** please use the forms on darkciphersystems.com (Report a bug, and Feature requests →
  ServerManagement).

## New
- **Save your sessions when you exit.** Exiting with tabs open asks **Save and exit**, **Exit without saving** or
  **Cancel** (tick **Don't ask again** to make it the default). Saved tabs come back at the next start, in the same
  panes, extra windows and tab groups, and reconnect:
  - terminals go back to their working folder (read from OSC 7 or the prompt; nothing is typed to find out), and a
    terminal you took into tmux with ⧉ tmux is re-attached to its session, after every reconnect too;
  - Files at their folder, File Commander with both panes, Remote Desktop, VNC, Manage and portal tabs;
  - quick-connect sessions with their settings, never a password;
  - PRODUCTION hosts reopen disconnected (press Enter or ↻), and locked hosts never reopen by themselves.
- **Named workspaces.** ▦ Workspaces in the title bar saves the open tabs as "Homelab", "VPS" or anything you like,
  and opens them again later, reconnected or disconnected. Workspaces can be replaced, renamed and removed (a removed
  one is archived, never deleted).
- Settings → Terminals & connections → **Saved sessions**; both settings are Group Policies. Everything is encrypted.
- **Alerts from terminals you aren't looking at.** A long command finishing, the terminal bell, a dropped session or
  a highlight rule you mark puts a dot on the tab, flashes the taskbar button and (when the app isn't in front) shows a
  Windows notification that takes you to the tab. It reads the screen, so it works inside tmux too. Each tab can mute
  its own.
- **Keyword highlighting.** Errors red, warnings yellow, success green, addresses cyan, HTTP status codes by class, plus
  your own regular expressions with a colour (and an optional alert). Only the drawing changes, never the output or
  the log; full-screen programs are left alone, and every pattern is checked for speed before it's used.
- **Ctrl+click** an IP address, a path or a link in terminal output: SSH to it, add it as a host, open the folder in
  Files, paste it quoted, or open the link (after showing it).
- **Snippet button bar and variables.** Mark a snippet "Show on the terminal button bar" and give it a scope (a host,
  a folder, a tag, an environment, a shell or local shells): it becomes a button above the terminals it fits.
  Right-click sends it to the tab group, the pane or every terminal. Snippets can use `{host}`, `{address}`, `{user}`,
  `{port}`, `{ask:Label=default}` and `{pick:Label|command}` (choose from a command's output on the host); every value
  is quoted for the shell, so an answer can never run a second command.
- **Command palette (Ctrl+Shift+P).** One box for hosts, open tabs, workspaces, snippets, pages, settings and actions;
  what you use most comes first.
- **Folder defaults.** Right-click a folder → ⚙ Folder defaults… sets the user name, credential, jump host,
  environment, terminal profile, VPN or tmux for every host in it and its sub-folders (the nearest folder wins). A host
  follows a field until you change it in the host editor, which shows where each value comes from.
- **Always in tmux.** An option (per host or folder too) takes every SSH terminal to a Linux or macOS host straight into
  your tmux session, so a drop never loses your work.
- **Remote Desktop through SSH.** A Remote Desktop host can connect through an SSH host (a bastion, or the same
  server): each session gets its own tunnel on 127.0.0.1, closed with the tab.
- **Built for big inventories:** a new self-test loads 10,000 demo hosts and holds saving, the Hosts screen, the palette
  and folder defaults to time budgets.
- Every new setting is a Group Policy ("Terminals and connections" and "Navigation and dashboard").

## Changed
- **Compact tab groups.** A group's name is printed once, on the first tab of the group, and the other tabs show the
  group's colour as a line underneath. Long titles (portal pages) end in "…" with the full title on hover, narrower
  inside a group, and every tab is a little slimmer.
- **Fixed: the AI Engineer with current Claude models.** The Claude API now refuses the `temperature` setting
  ("`temperature` is deprecated for this model"), so every question failed. It's no longer sent to the Claude API, and
  any AI server that refuses a sampling setting is asked again without it.
- **Faster, lighter.** A performance pass across the app:
  - **Starts faster:** the app no longer unpacks itself at every start (about a third quicker; it takes more disk
    space once installed, the download stays about the same).
  - **Big inventories:** folder counts, the Hosts tree and the workspace host pane no longer slow down with the number of
    hosts. Folders make their host rows when you open them, only the rows on screen are drawn, and the host pane's
    filter waits for you to stop typing.
  - **Saving is quicker:** the Hosts and Snippets pages refresh when you go back to them, not on every save behind
    other tabs; connecting no longer writes the store just to note "last connected" (that's saved a moment later, once).
  - **Idle tabs cost nothing:** a quiet terminal no longer wakes up 60 times a second, terminals you aren't looking at
    use less memory, and a server page behind other tabs stops its 5-second auto-refresh until you come back.
