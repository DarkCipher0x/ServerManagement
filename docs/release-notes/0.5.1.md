# ServerManagement 0.5.1 (2026-10-21) – DarkCipher Systems

A point release built from your feedback on 0.5.0 (docs/PLAN-0.5.1.md). It adds **VNC desktops** for Macs and Linux,
**Find hosts on the network** (with the AI suggesting names when it is on), **locks**: any category or single host,
folder, credential, provider, cloud account, portal or note behind admin approval, Windows sign-in or a password of its
own, a **LOGS** section with the audit log locked by default, Group Policy switches that turn off adding and changing
things, add-on installs behind UAC and policy, a full **BeyondTrust** page with certificate pinning, a **dashboard
editor** with a card catalogue, **Hyper-V** on Windows Server and Pro with a one-click module install, a **Quick Start**
that covers everything, one-click **Foundry Local** with phi-4-mini, and the MSI offering winget, Nmap and Foundry Local.
Dropdowns show their selection everywhere, and the File commander no longer connects by itself.
It upgrades every earlier install; the installer's version number is 0.5.1.

## New

### VNC: Mac and Linux desktops in a tab
- New host type **VNC (Mac / Linux desktop)**. The app's own RFB client, with no plug-in and no browser: RFB 3.3, 3.7 and
  3.8, and Apple's 003.889.
- Sign-in methods:
  - **Apple Remote Desktop** (the Mac's user name and password; Diffie-Hellman with AES-128);
  - the **VNC password**;
  - **VeNCrypt** with X.509 TLS (the certificate is pinned the first time you trust it);
  - none.
- Encodings: Raw, CopyRect, RRE, Hextile and ZRLE, plus desktop resize.
- **Through SSH by default.** The session goes through an SSH tunnel to the machine's SSH host (on a Mac, Remote Login
  must be on), so it is encrypted whatever the VNC server offers. "Direct" is there too; it warns when the stream isn't
  encrypted.
- In the tab:
  - scale to the tab or 1:1, view only;
  - keys Windows keeps for itself (Ctrl+Alt+Del, ⌘ / Super, ⌘ Space, ⌘ Tab, Alt+Tab);
  - send the clipboard (taking the remote clipboard is off unless the host allows it);
  - screenshot, reconnect.
- The host editor's **Test sign-in** runs the real handshake. An SSH host's menu → More tools → **Add its desktop (VNC)…**
  makes the tunnelled VNC host in one step. VNC tabs come back with the workspace.

### Find hosts on the network
- Hosts → ⋯ → **Find hosts on the network…** scans a private range (your subnet by default) for SSH (22, 2222), Remote
  Desktop (3389) and VNC (5900–5903), and Telnet too when it is allowed.
- It reads what answers to identify each machine: SSH banners give the distribution or device; Apple's Screen Sharing
  marks a Mac; Remote Desktop without SSH means Windows.
- A review grid lets you edit the names, folders, users and platforms, then tick and import. Addresses already saved are
  shown but not ticked. A Mac's desktop is tunnelled through its SSH host.
- **✦ Identify with AI** (when AI is on) suggests names, platforms and folders from the names, ports and banners only.
  Banners are sent as untrusted data, and every answer is checked before it fills the grid.
- Group Policy `AllowNetworkScan` turns off every scanner (ping sweeps, port scans, Nmap, the SSH finder and this).

### Locks and restrictions
- **Lock any category**: audit log, session logs, error log, observability, credentials, team, known hosts, hosts,
  infrastructure, cloud, portals, BeyondTrust, automation, File commander, notes, incidents, snippets, tunnels, add-ons,
  privacy and settings.
  - A lock opens with Windows admin approval (UAC), Windows sign-in (Hello or your password) or a password of its own
    (at least 12 characters; wrong tries slow down).
  - An opened lock stays open for 15 minutes (configurable). It closes when the app locks, when Windows locks, when the
    PC sleeps, or with "Lock everything now".
- **Lock single items**: a host, a folder (every host in it), a credential, an infrastructure provider, a cloud account, a
  portal or a note, from its right-click menu. A locked item shows 🔒 and opens nothing until it is unlocked:
  - its details are hidden;
  - connections, tunnels and the AI tools refuse it;
  - search leaves locked notes out;
  - the dashboard shows it by name only.
- **Add-ons and the local API never get a locked item**, even while it is open.
- **LOGS**: the audit log, session logs, error log and observability have their own sidebar section. The **audit log is
  locked by default** (Group Policy `LockAuditLog`).
- **Settings → Security & privacy → Locks & restrictions** lists every category and item lock, offers "Lock everything
  now", and holds the administrator settings (each change needs admin approval).
- **Group Policy**:
  - `LockedCategories` and `LockPolicyMode` (uac / signin) lock categories for everyone, and `LockOpenMinutes` sets how
    long an opened lock stays open;
  - `AllowUserLocks` and `AllowItemLocks` decide whether users may set their own locks;
  - twenty **Allow*** switches turn off adding, editing or deleting hosts, folders, credentials, cloud accounts,
    infrastructure providers and portals, and adding tunnels, snippets, shared libraries, integrations and add-ons.
  - Each switch is enforced in the screens and in the add-on bridge.

### Add-ons behind UAC and policy
- Installing, updating, enabling, granting a permission to and removing an add-on need admin approval
  (`AddonsNeedApproval`, on by default). Disabling and revoking never do.
- `AllowAddonInstall`, `AddonAllowedIds`, `AddonBlockedIds` and `AddonRequireSigned` (only Authenticode-signed programs)
  are checked:
  - when a package is inspected;
  - again at install;
  - every time an add-on runs or is applied (theme, portal browser, shared library).

### BeyondTrust, its own page (Settings → Integrations → BeyondTrust)
- The page has these cards:
  - **Connection** and **Password Safe**, each with **Test**;
  - **Checkout policy**: a reason prompt, and automatic check-in, always;
  - **Sessions**: whether Jump Items open in your access console or the web console, plus default Jump Group and
    Jumpoint filters;
  - **TLS**: trust-on-first-use certificate pinning for both appliances, admin-protected;
  - **Scopes**: what the integration may read and do;
  - **Audit**.
- The PRA and Password Safe clients now refuse a self-signed or changed certificate until you trust it.
- **Integrations has a page per integration**: BeyondTrust, Teams, Pingdom, Syslog, Log sinks & Sentinel, Dashboards &
  Grafana, E-mail, Local API, Automation, IDE and the portal browser.

### Dashboard editor
- **✎ Edit dashboard** shows or hides the built-in cards and adds cards from a catalogue:
  - a **host** or a **host folder**;
  - an **infrastructure provider**;
  - a **cloud provider**;
  - **Grafana**, **Microsoft Sentinel**, **Pingdom**, **BeyondTrust**, **Puppet** and **Entra ID**;
  - **pinned checks** (ping, TCP, HTTP(S), certificate, DNS, SPF / DMARC).
- Each card can be renamed, made full width, moved and removed. **Reset to default** asks first.
- Group Policy `DashboardLocked` and `DashboardCards` set a fixed layout.
- Cards read what the app already knows and contact nothing by themselves.

### Hyper-V on Windows Server and Windows Pro
- When the Hyper-V PowerShell module is missing, the app knows the edition and offers Windows' own fix as one click,
  behind UAC:
  - **Server**: `Install-WindowsFeature Hyper-V-PowerShell`;
  - **Pro, Enterprise and Education**: `Enable-WindowsOptionalFeature … Microsoft-Hyper-V-Management-PowerShell`;
  - **Home**: no fix (Home can't run the module); the app says so plainly.
- The provider says whether you are in "Hyper-V Administrators" or elevated. It shows the host's Windows version, VM
  generation, checkpoint type and Replica state.

### Quick Start covers everything
- Fifteen optional pages:
  - protection, category locks and personal settings;
  - AI, with the **one-click Foundry Local** set-up;
  - organisation sign-in (Active Directory, LDAPS, Entra ID);
  - **BeyondTrust**: each part is tested before it is kept;
  - cloud accounts, infrastructure, and importing connections (or finding them on the network);
  - Teams and Pingdom, log sinks, backup and the team library.
- Admin-protected values are asked for once, with one UAC prompt, at Finish.
- A step Group Policy already set says so. "Take me there when I finish" opens the right Settings page.

### AI: Foundry Local in one click, phi-4-mini everywhere
- **⚙ Set up Foundry Local** in the AI panel, Quick Start and Settings installs Foundry Local (winget), starts it,
  downloads phi-4-mini and checks that it answers.
- **phi-4-mini is the default on every PC**. A lighter model for small PCs is only suggested in the model guide, never
  chosen for you.
- New policies: `AiAllowEngineChange` keeps the engine and model the organisation chose; `AiAllowModelDownload` allows
  only models already on the PC.

### Installer
- The options page offers, each through winget:
  - **winget (App Installer) set up**, ticked;
  - **Nmap**, ticked;
  - **Microsoft Foundry Local**, ticked;
  - **Ollama**, now unticked.
- Each is an msiexec property for silent deployment: `INSTALLWINGET`, `INSTALLNMAP`, `INSTALLFOUNDRY`, `INSTALLOLLAMA`
  (`=0` skips one).

  "ServerManagement 0.5.1 – DarkCipher Systems". The guides' covers read "ServerManagement" under the company line.

## Fixed
- **Saving the backup schedule failed** with "A value of type 'System.Int32' cannot be converted to a 'System.Double'":
  the check behind every admin-protected whole number (schedule days, shortest password, lock open time…) couldn't
  read a number the app had just made. Fixed at the source; a test checks every protected number setting.
- **Turning on scheduled backups asks for the folder first.** Choosing "every N days" with no folder opens the folder
  picker; the schedule and the folder are approved together (one UAC prompt), and without a folder the schedule stays
  off. If no backup password is set yet, it is asked for next.
- **Dropdowns showed type names instead of the selection** (e.g. "Choice { Display = … }" in the host editor): the
  dropdown template now uses each list's display text. A test checks every dropdown in Settings and the host editor.
- The dashboard's Activity card showed audit entries while the audit log is locked; it now asks you to open the log.
- Settings → Data → "View error log" opened the log outside its lock; it now opens LOGS → Error log.
- Adding BeyondTrust Jump Items as hosts now respects the "adding hosts" policy.

## Security
- Locks are enforced below the screens:
  - in the SSH connector (host and credential);
  - in the cloud API factory (accounts);
  - in the AI capabilities (hosts, providers, notes, portals);
  - in the add-on bridge and the local API (strict: locked items are refused even while open).
- Lock passwords are PBKDF2-SHA256 (600,000 rounds), checked in constant time, throttled, and never stored. Opening a
  lock and every refusal are audited.
- The VNC client bounds every length and rectangle a server sends before allocating, and refuses:
  - VeNCrypt Plain without TLS on a direct connection;
  - anonymous TLS (it can't prove who the server is).
- VNC sign-in secrets (DES, MD5 and AES-ECB, as the protocols define) are wiped after use, and the stream is encrypted
  by the SSH tunnel by default.
- Host import scans private addresses only. The AI gets names, ports and banners fenced as untrusted data, and its
  answers are validated.
- BeyondTrust appliances are pinned like Proxmox and vCenter; the pins need admin approval.
- The self-test can never show a UAC or Windows sign-in prompt (refused and reported).
- Penetration-test probes for the new surfaces: docs/SECURITY-REPORT.md.
