# DarkCipher ServerManagement 0.1.13 (2026-10-19)

## New features

### Theme add-ons can rebrand the header
A theme add-on can now also replace the header logo (a PNG), the product name shown in the header and the window title, and the line under the name. It can put the logo on a rounded plate, for logos drawn for a white background.

### Sample theme 1.1.0
- **Colours:** a blue palette taken from the sample organisation's own branding (0.4.0 replaced it with the neutral "Ocean" sample).
  - **Light mode:** a white header with the logo, white pages, light grey panels and blue accents.
  - **Dark mode:** a deep blue, with the logo on a white pill.
- **Name:** the header and window title read the theme's product name, and the darkcipher0x prompt line is hidden.
- **Install or update:** Add-ons → ＋ Install add-on… (or **Update from file…**) → the theme's `.dcxaddon`.

## Behaviour changes
- **Enabled means in use:** enabling a theme add-on now puts it in use, overriding the app's light and dark themes. Disabling it, **Back to the default theme** or **Remove** brings back the DarkCipher palette, logo and name.

## Security changes
- **Logos are checked when the package is inspected:** they must be a PNG in the package, decoded with the PNG decoder only, ≤ 1 MB and ≤ 2048 × 2048 pixels. The product name and tagline must be plain text (≤ 60 characters).
- **Tamper check:** the logo is hash-checked with the theme's other files every time the theme is applied.

## Known limitations
- Only the main window's header, its title bar text and the Add-ons screen show the theme's name and logo. Dialogs, the installer, the Start menu, the taskbar icon and the About text still say DarkCipher ServerManagement.
- A theme changes colours, the header branding and the UI font. It doesn't change shapes (no pill buttons), terminal colours or remote desktops.
- **Not code-signed:** SmartScreen shows "unknown publisher", and in-app updates stay switched off.
