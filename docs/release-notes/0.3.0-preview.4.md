# DarkCipher ServerManagement 0.3.0-preview.4 (2026-10-20)

Pick-what-you-export encrypted files, an SSH key tool, a new quick connect, and another AI-terminal fix. It upgrades
0.3.0-preview.3; the installer's version number is 0.2.6.

## New
- **Choose exactly what to export.** Settings → Security → Encrypted backup / export (and the header's menu) now shows
  everything as a tick tree: hosts by folder, credentials, cloud accounts (Vultr, Contabo, Hetzner, Azure, Google Cloud)
  one by one, infrastructure providers, portals, tunnels, serial consoles, snippets, notes, incidents, trusted host keys
  and web certificates, app settings and saved reports. A line underneath counts what is ticked, including how many
  passwords/keys and cloud API keys. A host's jump hosts come along automatically; a credential you leave out is removed
  from the hosts that would use it (the summary names them). The file is the same password-encrypted .dcxbackup
  (PBKDF2-SHA256 600,000 rounds + AES-256-GCM), written, then read back to verify it.
- **Import with the same tree.** Opening an export shows what it holds, all ticked; untick what you don't want, then
  merge (keep mine / overwrite / keep both) or replace. App settings from a file are applied without touching
  admin-protected or Group Policy settings, the AI lock, or this PC's cloud accounts.
- **SSH key tool** (Credentials → 🔑 New SSH key…, and in Shared library): Ed25519 (recommended), RSA 3072/4096 or ECDSA
  P-256/384/521, made on this PC — no temporary files — straight into your vault or a shared library collection you
  can edit. Then copy the public key, install it on saved hosts you tick (like ssh-copy-id, PRODUCTION hosts confirmed),
  or export it.
- **Passphrase-protected key export.** Exporting a private key now offers a passphrase (recommended): the file is written
  in OpenSSH's own format, which ssh, PuTTYgen and this app read. The passphrase reaches Windows' ssh-keygen through the
  app's own helper over a one-shot pipe only your account can open — never on a command line or on disk.
- **Quick connect, rebuilt.** A protocol menu (SSH, Files (SFTP), Remote Desktop, Telnet while allowed, serial console,
  local shell, web UI in the in-app browser, your own SSH client), a dropdown (↓ or ▾) of **📌 pinned**, recent and
  matching saved hosts that you can move through with the arrow keys, and a **Connect** button. Pin any line to keep it
  at the top. Each line remembers its protocol (`rdp://admin@host`, `COM3 115200`, `wsl Ubuntu`, `https://nas:5001`…).
- **NPU offer.** When the AI Engineer starts on a PC with an NPU (a Copilot+ PC) that isn't being used, it asks whether
  to set up Foundry Local with phi-4-mini on the NPU, with a "Remember my choice" tick box (also a Group Policy:
  `AiNpuSetupChoice` = ask / always / never).

## Changed
- **phi-4-mini is the AI default wherever it runs**: on the NPU first (a Copilot+ PC's NPU is preferred), then a GPU
  with 4 GB+, then a CPU with 8 GB+ of RAM; smaller PCs get a lighter model. A first run with AI features on sets
  Foundry Local up by itself, as before. Not every PC has an NPU: then the GPU or CPU build is used.
- The header's cloud account picker is gone; switch accounts in Cloud providers (right-click a provider) or Settings.

## Fixed
- **The AI still didn't run some commands** (phi-4-mini): it called `terminal_run` with keys but no command, and then
  wrote `terminal_run --session … --command 'mpstat 1 24'` inside its answer, which "Review & run" typed into the shell
  as text. Now: a call missing a required argument gets a precise error naming what the tool takes, so the model
  corrects itself; a call written as a command line (`--key value`) inside a code block runs as the tool call (same
  approvals); and "Review & run" types the command itself, never the pseudo-call.

## Under the hood
- New self-tests: the export/import tree (jump hosts, stripped credentials, filtered accounts, counts-only audit), every
  key type, passphrase export through the real askpass helper, the key tool off screen, quick connect lines and pins,
  the NPU offer, and DarkCipher0x's second AI transcript.
