# DarkCipher ServerManagement 0.1.14 (2026-10-19)

## New features

### Infrastructure: much more of each provider's API
Every new change is offered only with **Allow changes**, greyed out with the reason when the account or the object's state doesn't allow it, confirmed first (type the name for anything that loses data, and in PRODUCTION), written to the Audit log, and reported **verified** only after the app read the result back.

- **Proxmox VE:**
  - Pause / Resume for VMs.
  - Snapshots: list, take (VMs can include RAM), roll back, delete.
  - Clone (empty VMID = the next free one), Migrate to another node, **Back up now** (vzdump), Convert to template.
  - Guest agent info (OS, host name, network interfaces).
  - Recent tasks on nodes, contents of storages.
  - A greyed-out action names the privilege the token lacks (VM.Snapshot, VM.Clone, VM.Migrate, VM.Backup, VM.Allocate).
- **VMware vCenter:** vCPU count, memory size, delete VM (powered off), guest & VMware Tools info, disconnect / reconnect hosts.
- **Hyper-V:** vCPU count, startup memory, rename, connect to another virtual switch, delete VM (disks are kept), rename checkpoints, VM details (adapters and IPs, disks, integration services).
- **Docker:** pause, unpause, kill, inspect, processes and resource usage of containers; remove images, networks and volumes.
- **Unraid:** restart / pause / unpause containers, pause / resume / reset VMs — when your Unraid API version has them.

### Cloud providers
- **Hetzner Cloud:** metrics of the last hour for servers and load balancers, alias IPs, network members, load balancer service update and reverse DNS, add / remove DNS records, record protection, primary nameservers of secondary zones. Every Hetzner Cloud operation is now reachable except the web console.
- **Contabo:** Object Storage (order, rename, usage, resize, cancel), VIPs (additional IPs: assign / unassign), reverse DNS (PTR) records, Tags, and ordering the Private Networking / Automated Backup add-ons.
- **Vultr:** IPv6 reverse DNS, reset IPv4 reverse DNS, remove an extra IPv4, ISO status, bare-metal VPCs and upgrades, Block storage snapshots, File System (VFS), sub-accounts.

### Coverage table
`docs/PROVIDER-API-COVERAGE.md` lists, for every provider, what its API offers, what the app exposes and why the rest is left out.

## Fixes
- **Freeze behind a blank error box:** a UI error that repeated on every layout pass (seen when switching to Cloud providers while SSH terminals were open) opened error boxes in a loop that could never paint. Now each failure is logged once and then counted, a screen that keeps failing is closed (never a session tab), and at most one box per failure per minute is shown, when the app is idle.
- **"Dispatcher processing has been suspended"** errors raised by terminal windows while WPF was drawing no longer open a modal box.
- **SSH auto-reconnect stops when the server refuses the key:** it used to retry every 30 seconds all night. The terminal now says why it stopped.
- **No more white flash** when a terminal, the document viewer or a web window opens in the dark theme.

## Behaviour changes
- Input defaults in Infrastructure forms can show the object's current value (for example the current vCPU count).
- Contabo has a new **Storage** group in the Cloud providers tree.

## Known limitations
- **Not offered, because the API doesn't have it:** vCenter snapshots and maintenance mode (SOAP API only), Contabo resize.
- **Not offered yet:** consoles (no VNC client in the app), Proxmox disk resize and hardware editing, vCenter disks / adapters / vMotion, Hyper-V dynamic memory, disk resize and live migration, Vultr logs, Unraid array and parity operations, Contabo region change.
- The new actions were tested against faithful fakes of each API, not against live servers.
- **Not code-signed:** SmartScreen shows "unknown publisher", and in-app updates stay switched off.
