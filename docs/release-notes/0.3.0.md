# DarkCipher ServerManagement 0.3.0 (2026-10-20)

The 0.3.0 release: the whole application encrypted and protected the way a company needs it, several profiles with
organisation sign-in, team features built in with group permissions, a network & mail toolbox, Ansible, VPN tunnels with
route steering, a customisable dashboard with pinned checks, Red Hat Satellite and Synology, Midnight Commander tools in
the File commander, a Vim-capable editor, syslog over TLS and e-mail notifications, LAN tools and monitoring, and the
first-run setup. It upgrades every 0.2.x and 0.3.0-preview install; the installer's version number is 0.3.0.

Everything in previews 1–4 is included (admin (UAC) protection and Windows Hello, Group Policy for every setting with
ADMX templates, an uninstaller that leaves nothing behind, the AI terminal fixes, pick-what-you-export, the SSH key
tool, the rebuilt quick connect) — see their notes below in the guide.

## New since preview.4

### Security, profiles and sign-in
- **The whole application is encrypted** under the data key; with a master password required at start (or Windows
  Hello) the Windows-account copy of the key is removed, so nothing is readable without them. **✓ Verify everything is
  encrypted** (Settings → Security) walks the store and the logs; the self-test fails the build on any plain file.
- **Profiles:** several in one installation, each its own encrypted store. The store you had is the first profile.
  New local profiles, or a profile that **signs in with your organisation**: Windows / Active Directory (the session's
  Kerberos — nothing typed), LDAP over TLS (LDAPS or StartTLS, certificate validated or pinned, SASL / Negotiate or a
  simple bind inside TLS), or Microsoft Entra ID (browser sign-in with PKCE, MFA and Conditional Access, id_token
  verified against the tenant's keys). Groups map to admin / operator / viewer (viewer = read-only); a required group
  gates the profile; a sealed proof opens it offline for a grace period. `RequireDirectorySignIn` (Group Policy) forbids
  local profiles. Settings → Security & privacy → Profiles; the status bar's lock menu switches profiles.
- **First-run setup:** a short guided, all-optional setup for a new store — protect the app, personal settings, AI on or
  off (local only), create or join a team. Run again from Settings → About.

### Team
- **Team features built in** — no add-on needed. Create a library, read your fingerprint to colleagues; they join from
  the folder with that fingerprint and a 6-digit code check. Team add-ons from older versions still work.
- **Groups:** named sets of members with per-collection access on top of each member's own, enforced by the encryption
  (keys wrapped for the group's members; leaving a group re-keys and lists credentials to rotate).
- Windows Hello confirms reveals, exports and approvals when "Confirm sensitive actions" is on. Team features are an
  admin-protected setting and a Group Policy (`TeamFeatures`).

### Network & mail toolbox (sidebar)
- **Network:** TCP port (the "telnet test" with the banner), traceroute, a live **mtr**, path MTU — from this PC or a
  saved server over SSH.
- **DNS:** every record type; **propagation** across Cloudflare, Google, Quad9, OpenDNS, your resolvers and any you add.
- **Web & TLS:** redirect chain, time, security headers, certificate; a TLS certificate check of any port with STARTTLS.
- **Mail domain:** MX + reverse DNS, SPF as a tree (10-lookup limit, evaluate a sending IP), DMARC, DKIM (selector or
  probe, key strength), MTA-STS, TLS-RPT, BIMI; **Blacklists** (18 IP lists, 5 domain lists; "refused" never shown as
  clean); the **email header analyser** (route and delays, authentication results, alignment) — all local.
- **WHOIS & ASN**, and a **History** of runs in the encrypted store.

### Ansible
- A control node (a WSL distribution or a saved Linux host); an inventory from your saved hosts (groups per folder,
  environment, platform); ping, facts, ad-hoc modules, playbooks (check / diff / limit / tags / extra vars / become),
  lint, vault, galaxy, inventory graph, doc, config, version. Nothing of a run is on a command line: a fixed bootstrap
  reads the job from stdin, vault and become passwords are stdin lines. PRODUCTION hosts mean typing PRODUCTION.

### VPN tunnels
- **WireGuard and OpenVPN** profiles imported from .conf / .ovpn: keys go to the vault, commands in the file are removed
  or refused. **Routes** decide what goes through the tunnel (split tunnel by default; "everything" is explicit). A host
  can **connect through** a profile: the tunnel comes up before its connections. Status shows the routes really
  installed. The engines need administrator approval (UAC) to install a tunnel.

### Dashboard
- **Pinned checks:** ping, TCP port, HTTP(S), TLS days left, a saved host's performance over SSH, a mail domain's
  SPF / DMARC — rows with state, history bars and a Checks tile; run by the dashboard's check rule (never silently); a
  change of state goes to the audit log and e-mail. 📌 from the toolbox.

### Infrastructure and servers
- **Red Hat Satellite / Foreman + Katello**: hosts, errata, content views, lifecycle environments, repositories,
  subscriptions, tasks; sync, publish, promote, errata install, remote execution — token over pinned TLS.
- **Synology DSM** (preview.8 work): shares, packages, Docker, storage, tasks, users.
- **DarkCipher portals** (dcx-ctl) in Infrastructure.
- **Mail server checks** per host: Postfix over SSH, TLS on 25 / 465 / 587, an open-relay probe, the domain's records.

### Files and editors
- **Midnight Commander in the File commander:** F9 menu bar, marking (Insert / Ctrl+T, +, −, *), quick search (Ctrl+S),
  brief listing mode (Alt+2), directory hotlist (Ctrl+\) and history (Alt+H, Alt+Y), find file, folder sizes, links,
  chown, archives as folders (zip / tar read-only with safe extraction), quick view, a command line, the user menu.
- **Text editor:** Vim mode with profiles (vimrc subset), find / replace, go to line, **line numbers** and **syntax
  colours** for shell, YAML, JSON, INI / systemd, nginx, TOML, Python, Dockerfile, XML, Markdown; a **hex editor**.

### Terminals, LAN, notifications (previews 5–7 work)
- Syslog over TLS (RFC 5425) and e-mail notifications (TLS only), both admin-protected.
- LAN discovery: ping sweep, SSH servers (results kept encrypted), port tests (built-in scanner or Nmap), a connection
  tool, scheduled monitoring with change reports.
- Middle-click autoscroll and scrolling menus; calmer environment colours; the ServerManagement header.

## Changed
- The TEAM sidebar section is always there (team features built in); Settings → Security & privacy gained Profiles and
  Team features cards; the Tunnels screen gained the VPN section; the host editor gained a VPN field.
- One new dependency: `System.DirectoryServices.Protocols` 8.0.0 (Microsoft) for LDAPS; everything else is as before.

## Fixed
- File commander archives: an entry sharing a shown name with an unsafe (`../`) twin could return the twin's bytes.
- The TLS check could build a new certificate chain (a network fetch) in offline mode; it now reads the chain Windows built.
- A malformed `https://` mail domain threw instead of being refused; Ctrl+\ works on UK keyboards; copying an archive
  entry with a name illegal on Windows is refused cleanly; the Vim "." repeat lost its count.
