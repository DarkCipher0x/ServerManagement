# ServerManagement 0.6.38 (2026-11-09) – DarkCipher Systems

**Public beta.** Built by an IT engineer, for engineers. Free and open source (MIT). Post-quantum ready.

## A note from the developer
ServerManagement is one of my favourite projects yet, and I'm excited to finally share it. I'm an IT infrastructure
engineer, and I designed it around the job: one encrypted workstation for your servers, network, hypervisors and
clouds, without licences or per-seat pricing. This is just the start. I'll keep adding as many systems as I can, and
all of it stays free and open source.

## Beta: please read
- **This is a beta.** Expect rough edges, and keep backups of anything important (Settings → Data & backups).
- **The installer and the app aren't code-signed yet.** Windows SmartScreen may say "Windows protected your PC": choose
  **More info → Run anyway** only if the SHA-256 of your download matches the one published with the release. The
  update information inside the app *is* signed, twice (ECDSA P-256 and post-quantum ML-DSA-65), and the app refuses an
  update unless both signatures match.
- **Testers are very welcome.** Many integrations are built against the vendors' published APIs but haven't yet been run
  against a live account, because I don't have access to those services. If you use any of them, I'd love to hear
  whether it works:
  - Microsoft 365 admin (Intune, Defender, Entra), Windows 365 Cloud PCs and Microsoft Teams;
  - the OpenAI API engine (new in 0.6.34: built to OpenAI's published Responses API, tested against a local stand-in);
  - the new Redfish (HPE iLO, Supermicro, Dell iDRAC, Lenovo XCC), HPE GreenLake and Sophos Central providers (0.6.34:
    built to the vendors' published APIs, tested against stand-ins);
  - Bitwarden (Password Manager and Secrets Manager, cloud and self-hosted / Vaultwarden);
  - UniFi (Network on a console or through the Cloud Connector, and Site Manager);
  - BeyondTrust Privileged Remote Access, Pingdom, Grafana / SIEM links, Elasticsearch and Loki log sinks;
  - Contabo, Hetzner Cloud, Azure and Google Cloud;
  - VMware vCenter, Hyper-V, Proxmox, Unraid, Docker, Puppet, WSL and serial consoles.
- **Bugs and feature requests:** please use the forms on darkciphersystems.com (Report a bug, and Feature requests →
  ServerManagement).

## New
- **Calls in CipherChat (preview).** **📞 Call** and **🎥 Video** on a room start an end-to-end encrypted voice or video
  call with its members, made exactly as CipherChat's own Windows app makes them: its own call screen runs in a window
  of its own, can use only the camera and microphone, and can talk only to the chat server. The call's safety words are
  in the window title (the same on every device when nobody is in the middle). An incoming call rings in the corner of
  the screen with **Answer** and **Decline**, and stops when it's answered on another device, missed, or the chat is
  locked. Calls follow the `ChatAllowCalls` policy and need Windows' WebView2 runtime. They haven't been made against a
  live CipherChat server yet, so please tell me how they work with yours.
- **Pictures in chat.** A picture you add (a screenshot, say) shows a preview above the message box before you send it
  (✕ takes a file out, Esc all of them), and is sent with a small preview as CipherChat's own apps do. Pictures in a
  room show inline; click one to save it.
- **The chat side panel remembers itself:** whether it's open, its width and the pinned room come back at the next
  start (the room once that chat is unlocked).
- **Two new dashboard tiles:** **Chat contacts** (people you haven't verified yet; a changed key shows as a warning) and,
  while you're signed in to a server's administration, **Chat server** (sign-up requests waiting).

- **Stream manager for Twitch (needs its add-on, not yet released).** As in 0.6.37: the app contains a stream manager
  that a separate "Stream manager for Twitch" add-on switches on (a dashboard, chat, an activity feed, stream info,
  clips, markers and ads with keys that also work while you're in a game, and Streamer.bot on your streaming PC).
  Without the add-on nothing of it loads or shows, and Group Policy `StreamFeatures` = 0 keeps it off. The add-on will
  be published separately once it has been tested against Twitch.
