## Under the hood (the start of the 0.2.0 restructure, `docs/history/PLAN-0.2.0.md`)
- The source is kept in a local git repository, with a solution file (`DarkCipher.ServerManagement.sln`); `build.ps1` builds the solution.
- Code below the screens no longer talks to the window directly: dialogs, the status line, navigation and the UI thread go through small seams (`Ui.Dialogs`, `Ui.Window`, `Ui.Thread`), and errors through `Log.Write`. A self-test scan keeps it that way.
- One capability registry: the AI operator's built-in tools, the features' tools and what add-ons call through `app.call` are the same 44 named entries in `Services\Capabilities.cs`; names, order, risks and permissions are unchanged (checked against a saved list). Secret masking moved to `Redaction`.
- Nothing you use changed; everything behaves as in 0.1.19.
