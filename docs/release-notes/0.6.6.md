# ServerManagement 0.6.6 (2026-10-22) – DarkCipher Systems

Microsoft 365 admin (Intune, Defender and Entra, read-only) and a tmux button in the terminal.

## Added
- **Microsoft 365 admin** (SERVERS → Microsoft 365 admin), read-only, signed in as you through Microsoft Graph:
  - **Intune:** managed devices with compliance, OS, user, last check-in, model and encryption.
  - **Defender:** incidents and alerts, newest first, with severity, status and classification.
  - **Entra:** users, groups, devices, sign-ins (Entra ID P1) and risky users (Entra ID P2).

  Pick a list, ↻ Load, filter, and double-click an item (or Open in portal) to open it in the real admin centre in a
  tab; Portals ▾ opens the Intune, Defender and Entra admin centres. Set up once in Settings → Integrations →
  Microsoft 365 admin: your tenant and an app registration with the read-only permissions listed there (admin consent;
  changing it needs admin approval). Actions (sync, wipe, resolve, disable…) come in a later release.
- **⧉ tmux in the terminal.** On an SSH session to a Linux or macOS host, ⧉ tmux starts tmux, or reattaches your session
  there. If tmux is missing it offers to install it with the host's package manager (apt, dnf, yum, zypper, pacman,
  apk or brew); sudo asks for its password right in the terminal. **Paste your own tmux config** in Settings → Terminals
  & connections → tmux: it is written to `~/.config/dcx-servermanagement/tmux.conf` on the host and used for the session
  (your own `~/.tmux.conf` is never touched). The session name is yours to choose (default "main").

## Security
- Microsoft 365 admin asks only for read permissions, one sign-in per service (Intune, Defender, Entra) so a tenant
  that consented to one isn't asked for the others; requests go only to graph.microsoft.com, and links only to the
  Intune, Defender and Entra admin centres (a link elsewhere from Graph is dropped). Nothing read is stored; each list
  loaded goes into the audit log.
- tmux: your config travels as base64 over the SSH connection's own channel and lands in a file only you can read
  (directory 700, file 600); the session name is checked, so nothing from the settings reaches the shell unquoted.
  Installing asks first every time (with the PRODUCTION banner on production hosts), and every start is audited.
