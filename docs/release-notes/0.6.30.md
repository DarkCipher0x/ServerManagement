## New
- **Your PC's SSH keys, in one step.** The app can copy the SSH keys already in your Windows account's `.ssh` folder
  into its encrypted credential store:
  - **Quick Start** has a new **Your SSH keys** page. OpenSSH's default keys (`id_ed25519`, `id_ecdsa`, `id_rsa`) are
    ticked, and the first one can become quick connect's key.
  - **Credentials → ⇩ From ~/.ssh…** does the same at any time.
  - A key with a passphrase keeps it (you're asked when it's copied). A key that's already stored is shown as such.
    FIDO security keys (`…_sk`) are listed but can't be used yet.
  - **Pick up new SSH keys from ~/.ssh at start** (Settings → Terminals & connections, or the tick box on the Quick
    Start page; off by default, also a Group Policy) copies
    new keys without a passphrase each time the app starts. Each key is picked up once, so a key you remove stays
    removed.
  - The files themselves are only read, never changed, moved or removed.

## Security
A full penetration-test and debugging sweep of everything added since the first public beta (the Security report,
§4g). Seven issues were found and fixed:
- **PowerShell folders and snippets.** PowerShell ends a quoted string at curly quotes too, not just `'`. A server could
  print a fake PowerShell prompt naming a folder with a curly quote, and reopening that saved session would have typed
  the rest as a command. Every PowerShell quote is now escaped, in restored folders and in snippet values.
- **Shared libraries and Remote Desktop / VNC through SSH.** A shared library's host could tunnel through one of your
  own SSH hosts. Shared hosts now tunnel only through SSH hosts from the same library.
- **Copying between two servers.** A hostile SFTP or SCP server could list a name containing `/` or `..`, so a
  host-to-host copy or sync wrote outside the target folder on the other server. Those names are now dropped.
- **Snippets in cmd and on network devices.** These shells can't be quoted reliably, so a value with characters such
  as `&`, `|`, `;`, `%` or quotes is now refused there, and the snippet isn't sent to any terminal.
- **SSH key files** are read with a size cap, their names are shown without hidden direction-changing characters, and
  a key that would take minutes to check is listed but not tried.
- PowerShell snippet values starting with `-` or containing `@` or `,` are now quoted.
- A server reporting an impossible file time no longer breaks an SCP folder listing.

The penetration-test suite now has 248 attack probes and the fuzzer covers 48 parsers; every one passed.
