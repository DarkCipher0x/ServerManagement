# ServerManagement 0.6.7 (2026-10-23) – DarkCipher Systems

Sessions open inside the Hosts tab, beside its folder pane.

## Changed
- **Sessions open inside the Hosts tab.** What you connect to from the Hosts page (Connect, double-click, Files, Manage,
  Remote Desktop, VNC, File commander) now opens as a tab *inside* the Hosts tab, next to its first tab, **All hosts**
  (your host list). The folder pane stays on the left, pinned or as the slim Hosts tab that slides out, so you can pick
  the next host without leaving the session. While a session is in front, the page's title and toolbar step aside to
  give it the room; click **All hosts** to get them back.
  - The tabs inside work like any other: split right / down, drag one out to the main window or another window, and
    "switch to the open tab" finds them.
  - Other screens (Settings, Notes, Reports…) still open as their own tabs, never inside Hosts.
  - Closing the Hosts tab moves its sessions to ordinary tabs; nothing is closed.
  - **Prefer separate tabs?** Settings → Navigation → Sidebar → **Open sessions from Hosts** → As separate tabs (also in
    Hosts → More ▾, and the Group Policy `HostsOpenIn`: `hosts` / `tab`).
- **Slide-out panes over a session open beside it.** A terminal or remote desktop is a native window that nothing can
  be drawn on top of, so the Hosts folder pane (and the host pane of extra windows), when they slide out over a session,
  now open beside it for as long as they are out. Over the host list they still slide over.

## Security
- No change to storage, encryption or network access.
