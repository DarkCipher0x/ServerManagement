# ServerManagement 0.6.44 (2026-11-09) – DarkCipher Systems

**Public beta.** Built by an IT engineer, for engineers. Free and open source (MIT). Post-quantum ready.

## Beta: please read
- **This is a beta.** Expect rough edges, and keep backups of anything important (Settings → Data & backups).
- **The installer and the app aren't code-signed yet.** Windows SmartScreen may say "Windows protected your PC": choose
  **More info → Run anyway** only if the SHA-256 of your download matches the one published with the release. The
  update information inside the app *is* signed, twice (ECDSA P-256 and post-quantum ML-DSA-65), and the app refuses an
  update unless both signatures match.
- **Testers are very welcome**, especially for CipherChat calls and live session sharing against your own CipherChat
  server, and Windows management against remote computers.
- **Bugs and feature requests:** please use the forms on darkciphersystems.com (Report a bug, and Feature requests →
  ServerManagement).

## New
- **Auto-hide for the hosts panel, where you can find it.** When the hosts panel is set to collapse, its header now
  has an **Auto-hide** switch next to HOSTS. Untick it and the panel no longer slides out whenever the pointer passes
  the Hosts strip: one click on the strip opens it, a second click folds it. Right-click the Hosts strip for **Turn
  auto-hide off / on** and **Pin the hosts panel open**. Both stay in step with Settings → Appearance → Hosts panel,
  and are locked when Group Policy sets `HostsDockHover`.
