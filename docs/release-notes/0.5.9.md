# ServerManagement 0.5.9 (2026-10-21) – DarkCipher Systems

Opening something that's already open switches to its tab, and the installer leaves alone what you already have.

## Changed
- **No more duplicate tabs.** Connecting to a host that already has a terminal, Remote Desktop or VNC tab open now
  switches to that tab instead of opening another connection. The same goes for a host's Files, the file commander and
  local shells (PowerShell, Command Prompt, WSL). If the open session has dropped, the tab says so: press Enter or
  ↻ Reconnect.
  - Want a second session on purpose? Hold **Shift** as you connect, or right-click the host → **⧉ New connection
    (another tab)**, or right-click the tab → **⊞ Duplicate session**.
  - Prefer the old behaviour? Settings → Terminal → untick "Switch to an open tab of the same host instead of opening
    another". Administrators can set it by Group Policy (`ReuseOpenTabs`).
  - Restoring your workspace still reopens every tab you had, including several of the same host.
- **Pin Hosts in one click.** A **📌 Pin beside sessions** button now sits at the top of Hosts (it was only under
  More ▾ in 0.5.8).
- **The installer only ticks what's missing.** winget, Nmap and Foundry Local are ticked only when they aren't already
  installed, the same way WebView2 always was. A value given on the msiexec command line still wins.

## Security
- No change to storage, encryption, network access or protected settings. One new Group Policy (`ReuseOpenTabs`), now
  216 in all.
