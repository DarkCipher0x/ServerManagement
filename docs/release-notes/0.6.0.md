# ServerManagement 0.6.0 (2026-10-21) – DarkCipher Systems

A new themed setup program, and the host pane done the way it was meant: like SecureCRT's Session Manager.

## Added
- **A modern setup program in the DarkCipher theme.** `DarkCipherServerManagement-0.6.0-Setup.exe` is the new way to
  install by double-clicking: a dark, teal-accented window with the logo and version, then:
  - **Install** (or **Update** when an older version is on the PC; your data is kept);
  - **Options**: the install folder and one switch per extra (desktop shortcut, WebView2, winget, Nmap, Foundry Local,
    Ollama). Anything already installed shows **Installed** and is left alone;
  - progress with a single administrator approval, then **Open ServerManagement now**;
  - when the same version is installed: **Repair** or **Uninstall** (with "Also remove my data and settings").

  The MSI is unchanged and still deploys silently and by Group Policy or Intune. The setup program also runs silently:
  `/quiet`, `/quiet /uninstall`, `/log <file>`. It is a template the other DarkCipher apps can reuse
  (`installer\Setup\README.md`).

## Changed
- **The host pane, like SecureCRT's Session Manager** (replacing 0.5.8's "pin the whole Hosts page"). 📌 **Pin host
  pane** puts a slim pane beside your sessions: a filter, ⌨ Connect, ＋ Host, ✎ Properties, your folders with their hosts
  inside, ★ Favourites and ＋ Folder. Double-click or Enter connects (to the open tab if there is one); right-click a host
  for Connect, New connection, Files, Manage, Properties and favourites, or a folder to add a host or sub-folder. Pinned or
  auto-collapse as before; the Hosts page itself stays an ordinary tab.

## Security
- The setup program runs unelevated and asks Windows for administrator approval only to install, through Windows
  Installer, as the MSI does. Its file name is never plain `Setup.exe`, which Windows would load compatibility shims
  into (a DLL-hijacking risk WiX refuses). It reads only registry entries and files that show whether an option is
  installed.
- The host pane follows locks: a closed folder lock shows nothing inside until it is opened, and a locked host shows its
  padlock and no address.
- No change to storage, encryption or network access.
