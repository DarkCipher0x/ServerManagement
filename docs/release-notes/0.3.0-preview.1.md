# DarkCipher ServerManagement 0.3.0-preview.1 (2026-10-20)

The first 0.3.0 preview: security settings protected by an administrator (UAC), and Windows Hello. It upgrades 0.2.2;
the installer's version number is 0.2.3 (a preview must sort below the final 0.3.0, which will upgrade it).

## New

### Admin protection (UAC)
- **Settings → Security & privacy → Admin protection** (the first card). Security settings are kept where only
  administrators can change them: AI features, internet AI providers, masking secrets, AI auto-run; offline mode, its
  approved list and add-ons while offline; the local API and its port; Telnet; lock when Windows locks, auto-lock,
  sandbox mode; Windows Hello sign-in and confirmations. Settings marks them with 🛡.
- **"Protect these settings now…"** protects them all with one UAC prompt. After that, changing one asks Windows for
  administrator approval, and a second window shows exactly what changes, for which Windows user and why. Nothing is
  written unless you press Apply.
- **Stricter at once:** offline mode on, Telnet off and similar changes apply straight away for this session; approval
  makes them last.
- Stored in `HKLM\SOFTWARE\DarkCipher Systems\ServerManagement\Protected` (administrators write, everyone reads),
  never with a password or key. A key others could change is ignored and reported. Only the installed app can ask for
  approval; a portable copy says it can't protect settings.

### Windows Hello
- **Sign in with Windows Hello** (face, fingerprint or PIN): a TPM-backed Hello key unlocks the data key; the master
  password stays as the fallback. Works on the lock screen too.
- **Confirm sensitive actions with Windows Hello:** before opening a saved credential, exporting a private key, any
  export or backup, and protected setting changes (the master password when Hello isn't available).
- **AI features lock with Windows Hello** instead of a password.
- **The prompt opens in front of the app:** the app tells Windows which window is asking (Windows 11).

## Fixes
- **Security:** "Set / change master password" no longer lets the password be replaced when the current-password
  prompt is cancelled.

## Not tested by hand yet
The real UAC prompt and approval window, Windows Hello sign-in and the prompt in front need trying on a real PC; the
self-test uses stand-ins for both (it never shows a prompt).
