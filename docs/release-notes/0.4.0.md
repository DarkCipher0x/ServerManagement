# DarkCipher ServerManagement 0.4.0 (2026-10-21)

The 0.4.0 release: the app named and filed as **DarkCipher Systems** everywhere, your organisation's branding and colours
from Settings, log shipping to Elasticsearch / OpenSearch, Grafana Loki, Azure Monitor / Microsoft Sentinel, Splunk,
Graylog and webhooks with an Observability screen and Grafana dashboards, reports for this PC with Event Viewer exports
and AI analysis, credentials in folders and types, session logs controlled by policy and forwarded over syslog, a dashboard
you unlock and rearrange, more mature Ansible, many more Azure and Google Cloud screens, the second security sweep's fixes,
a penetration-test suite with a published security report, and the full documentation bundle with every release.
It upgrades every earlier install; the installer's version number is 0.4.0.

## New

### Branding & colours (Settings → Appearance)
- Give the app your organisation's look without an add-on: product name, tagline, a PNG logo on an optional plate, the
  UI font and every colour key for dark and light, with live swatches. **Apply**, **Fill from the current theme**,
  **Clear**, **Import** a theme.json, **Export** the JSON, and **Export as theme add-on** (a theme-only `.dcxaddon`
  installable anywhere). A company pushes the same look by Group Policy (`BrandingTheme`, `BrandingLogoPath`); a chosen
  theme add-on still wins. The sample theme in the source is now the neutral **Ocean** theme.

### Observability (sidebar) and log sinks (Settings → Integrations)
- **Log sinks:** the audit log, the application log and (if you choose) terminal session logs as JSON documents to
  **Elasticsearch / OpenSearch** (bulk API), **Grafana Loki**, **Azure Monitor / Microsoft Sentinel** (Logs Ingestion
  API, signing in with an Azure subscription's app registration), **Splunk** (HTTP Event Collector), **Graylog** (GELF)
  or any **HTTPS webhook**. HTTPS only, pinnable certificates, secrets masked before anything leaves, an encrypted queue
  while a sink is unreachable, per-sink back-off, up to 12 sinks. The sink list is admin-protected and a Group Policy
  (`ObserveSinks`, no secrets); keys and tokens stay in the encrypted settings.
- **Observability screen:** every sink's state, last sent and errors; events shipped per minute over the last hour; your
  **Grafana dashboards** listed through its API and opened in the app's browser window; links to Kibana, OpenSearch
  Dashboards, Microsoft Sentinel, Splunk or any SIEM (`ObserveLinks`, a policy).
- A failing sink is e-mailed about like failing syslog.

### Reports: this PC and the Event Viewer
- The fleet report can include **💻 This PC**: Windows facts over WMI (system, uptime, updates, disks, services, Defender,
  firewall, BitLocker, listening ports, processes, scheduled tasks) and the **Event Viewer** (System, Application and any
  log you name; critical / error / warning) digested like Linux logs, with built-in rules that suggest PowerShell fixes.
- **Export events** as `.evtx` (one per log, opens in Event Viewer) or as a formula-safe **CSV**.
- The **AI analysis** now reads Windows evidence too (PowerShell suggestions for this PC, shell for servers).

### Credentials in folders and types
- Credentials have a **folder** and a **type** (password, SSH key, API token, certificate, cloud, database, other). The
  Credentials screen has a folder list with counts, a type filter and a search; move, rename and remove folders, set types.

### Session logs by policy, forwarded
- Settings → Terminal & connections → **Session logs**: per profile (as before), **on** for every session, or **off**;
  the same as the Group Policy `SessionLogs`. Logged sessions can be **forwarded over syslog TLS** (msgid `session`) and
  to the log sinks (kind `session`), masked like every message.

### Dashboard
- **Unlock** the dashboard (Customise ▾ or the lock) and **drag and drop tiles** into the order you want; lock again.

### Ansible
- **Syntax check**, **List tasks**, **List hosts**, **Skip tags**, **Start at task**, **Forks**, **Install collection**
  and **Installed** (collections and roles); output **Copy**, **Save** and **Add to incident**.

### Microsoft Azure and Google Cloud: more screens
- **Azure:** VM scale sets (start / deallocate / restart all, scale), availability sets, VM extensions, network
  interfaces, private DNS zones with records and virtual network links, container instances (start / stop / restart),
  PostgreSQL and MySQL flexible servers (start / stop / restart), Resource Health and Advisor recommendations.
- **Google Cloud:** managed instance groups (resize), instance templates, machine images, Cloud Functions, Artifact
  Registry, routes, Cloud Routers / NAT, backend services, health checks, SSL certificates, VPN tunnels, Pub/Sub topics
  (create) and subscriptions, Cloud SQL **Back up now**.

### Network & mail toolbox
- **Traceroute and mtr rewritten:** three probes per hop in parallel, progress per hop while it runs, "destination
  unreachable" shown as the last hop, a stop after six silent hops, and a plain verdict ("reached in 9 hops",
  "no answer after hop 5: the path drops ICMP").

### Import & export
- The **Import & export** tab now leads with the encrypted **pick-what-you-export** tree (`.dcxbackup`, its own password)
  and the matching import; the appearance JSON stays for looks only.

## Changed
- **Named and filed as DarkCipher Systems:** the window title is **ServerManagement — by DarkCipher Systems**; data moves
  from `%APPDATA%\DarkCipher\ServerManagement` and `%LOCALAPPDATA%\DarkCipher\ServerManagement` to
  `…\DarkCipher Systems\ServerManagement` on first start (an audited one-time move); the install key is
  `HKLM\SOFTWARE\DarkCipher Systems\ServerManagement\Install`; every assembly's company is DarkCipher Systems. The
  uninstaller removes old and new folders.
- **Infrastructure:** the DarkCipher portal provider is called **DCX-CTL**.
- **No white flash:** every window (the main window, dialogs, pop-outs, the setup) is painted in the theme's background
  before its first frame; the system message boxes became themed dialogs.
- **File commander:** after keyboard navigation (marking, quick search, the keyboard cursor) a mouse click takes over
  cleanly; file and button commands work again at once.
- **Settings:** the About card and theme texts no longer describe internal design material.
- **Group Policy:** 145 policies (every new setting included); the category "Syslog, log sinks and notifications".

## Security
- **Second sweep fixes:** server-sent file names can't escape the download folder (`..\`, drive letters and separators
  are neutralised — SFTP downloads, shares and whole-tree downloads); CSV exports are formula-safe (cells starting with
  `=`, `+`, `-`, `@`, tab or CR are quoted as text); process ids and mount points reaching remote commands are quoted.
- **Log sinks:** HTTPS only (TLS 1.2+), SHA-256 pins, no credentials in URLs, bounded and masked server answers, no
  secret in any body, path, status, message or audit line; the Azure Monitor token is the Azure subscription's own
  certificate sign-in for a second scope, cached apart.
- **Penetration-test suite** (`SelfTestPentest.cs`, run on every build): path traversal, formula and shell injection,
  hostile Group Policy and protected values, nesting bombs, 1 MB answers and escape-laden text, XXE / entity expansion /
  external DTD against the Event Viewer parser, 50,000-row and off-host Grafana answers, hostile theme files and logos.
  Results in `docs/SECURITY-REPORT.md` (and the Security-Report PDF of the release).
- **Keyboard-focus tooltips** of the off-screen test window are cancelled before they open in the self-test (nothing
  ever appears on screen); a tooltip of any on-screen window still fails the run.

## Release bundle (new rule)
Every release folder now carries, besides the MSI, portable zip, policy templates, SBOM and checksums: the **complete
guide**, **user guide**, **developer guide**, **business / administrator guide** (Active Directory, LDAPS, Entra, Group
Policy, syslog and log sinks, team features, branding, data, uninstall), the **security report** and the **project
structure** as PDFs, and the **sanitised source archive** (every tracked file minus private notes, scanned for local
paths, private addresses and keys before it is written). `build.ps1` fails when any is missing.
