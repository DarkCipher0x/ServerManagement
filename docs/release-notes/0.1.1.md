# DarkCipher ServerManagement 0.1.1 (2026-10-18)

The first numbered iteration after the 0.1.0 development builds. Every build from now on gets its own version, and earlier installers are kept.

## New in 0.1.1
- **Terminal profiles.** A profile sets the colour scheme (app theme, Classic, Solarized dark/light, Green screen), the cursor style and blink, and the encoding: UTF-8, ISO-8859-1, Windows-1252 or IBM437, for SSH and Telnet input and output. It also sets scrollback (up to 200,000 lines), "Backspace sends ^H", key mappings (`Ctrl+Shift+F5 = \e[15;6~`) and logging.
  - Set it per host in the host editor, or switch it for one session from the terminal's right-click menu.
  - Settings → Terminal profiles.
- **Search the scrollback.** Press Ctrl+Shift+F or ⌕. Matches are shown newest first, as "n of m", with match case and regular-expression options; wrapped lines are searched as one line.
- **Session logging.** Encrypted, optionally timestamped logs of terminal output.
  - Logs are readable (colour codes stripped, progress bars resolved), with no host names in the file names.
  - New **Sidebar → Session logs** screen: read, search, delete, or "Export as text" (plain text, so the app warns first).
  - Session logs move with the data store.
- **Broadcast input.** Type once into several terminals: all open terminals, a tab group, or a pane.
  - It asks first. A set that includes PRODUCTION means typing PRODUCTION.
  - Every member shows a yellow strip with Stop.
- **Tab groups.** Name a set of tabs. The tab headers show the group in colour, and the Group menu can step through the group, broadcast input to it, reconnect, disconnect or close it.
- **Telnet for legacy devices.** Off by default; Settings → Terminal & connections → Allow Telnet asks first.
  - The host editor gets a Telnet type, and quick connect accepts `telnet host [port]` or `telnet://host:port`.
  - It sends the window size and terminal type, and Enter as CR LF.
  - Every Telnet session is marked unencrypted, never auto-types credentials, respects offline mode and is audited.
- **Engineering overview (dashboard), rebuilt:**
  - active sessions by type (connected / open, PRODUCTION first);
  - local application warnings, each with a fix button;
  - environment and safety;
  - infrastructure with last-known state;
  - active incidents, transfers, recent connections and notes, Vultr, activity.
  - Remote checks follow a visible rule (manual / when it opens / every 5–60 minutes while on screen). Infrastructure providers are opt-in, and nothing is polled silently.
  - Cards can be moved, hidden and reset.

## Fixes
- **Session logs no longer run lines together** when a shell moves the cursor instead of printing a line break (Windows console programs).
- **Moving the data store** now also moves session logs, and the uninstaller's "remove your data" includes them.
- **Self-test reliability:** a terminal left auto-reconnecting to a refused test host caused rare, random "error-log entry" failures. Fixed at the source.
- **Version numbers:** only one line sets the version, and the build refuses to overwrite an existing installer.

## Before you rely on it
- **Verified by the automated self-test on the build PC** (151 checks, no failures; an extended endurance run as well): everything above, against loopback servers, real local shells and fakes.
- **Not yet verified against real systems:**
  - SSH to real servers; Remote Desktop sign-in;
  - Vultr, Proxmox, Docker and Unraid;
  - real AI model calls; Telnet to real devices; serial hardware;
  - sleep / resume and VPN changes.
  - Try these by hand (OUTSTANDING.md has a checklist) before trusting them with production systems.
- **Not code-signed:** SmartScreen shows "unknown publisher", and in-app updates stay switched off until a signing certificate is in place.
