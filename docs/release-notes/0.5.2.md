# ServerManagement 0.5.2 (2026-10-21) – DarkCipher Systems

A fix release from your feedback on 0.5.1.

## Fixed
- **A right-click in a text box stopped the app taking clicks.** In 0.5.1, right-clicking in LOGS → Error log (and other
  text fields) opened Windows' built-in text menu inside the main window; afterwards the sidebar and everything else
  ignored the mouse, and closing the window left the app running until it was ended in Task Manager. Every text box now
  uses the app's own menu: highlight text, right-click, **Copy** (also Copy all and Select all; Cut and Paste where you
  can type; Find… in read-only text). The highlight stays visible while the menu is open. Boxes with a menu of their own
  (terminal output, notes, editors) keep it. A self-test checks the menus and every text box of the Error log screen.
- **Paste** no longer fails while another program holds the clipboard: it is greyed for a moment instead (text menus,
  the terminal menu and the Toolbox headers "Paste" button).

## Changed
- **"(admin approval)"** on buttons is the same colour as the word before it (smaller and in italics only).
- **Backup & restore**: the buttons read "⤓ Back up now…" and "⤒ Restore or import…"; both still show the tick tree.

## Security
- The menu every text box now gets automatically has editing commands only (Copy, Cut, Paste, Copy all, Select all,
  Find). It never offers Save as or Share, because such a box may show a secret (a key typed into a plain field, recovery
  codes): nothing reaches a file or another app that Windows' own menu didn't already allow. A self-test enforces it.
- No change to storage, encryption, network access, policies or the protected settings.
