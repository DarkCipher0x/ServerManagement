## Beta: please read
- **This is a beta.** Expect rough edges, and keep backups of anything important (Settings → Data & backups).
- **The installer and the app aren't code-signed yet.** Windows SmartScreen may say "Windows protected your PC": choose
  **More info → Run anyway** only if the SHA-256 of your download matches the one published with the release. The
  update information inside the app *is* signed, twice (ECDSA P-256 and post-quantum ML-DSA-65), and the app refuses an
  update unless both signatures match.
- **Testers are very welcome.** Many integrations are built against the vendors' published APIs but haven't yet been run
  against a live account, because I don't have access to those services. If you use any of them, I'd love to hear
  whether it works:
  - Microsoft 365 admin (Intune, Defender, Entra), Windows 365 Cloud PCs and Microsoft Teams;
  - Bitwarden (Password Manager and Secrets Manager, cloud and self-hosted / Vaultwarden);
  - UniFi (Network on a console or through the Cloud Connector, and Site Manager);
  - BeyondTrust Privileged Remote Access, Pingdom, Grafana / SIEM links, Elasticsearch and Loki log sinks;
  - Contabo, Hetzner Cloud, Azure and Google Cloud;
  - VMware vCenter, Hyper-V, Proxmox, Unraid, Docker, Puppet, WSL and serial consoles.
- **Bugs and feature requests:** please use the forms on darkciphersystems.com (Report a bug, and Feature requests →
  ServerManagement).

## New
- **Folder sync in File Commander, FreeFileSync-style.** A new **⇄ Sync** button syncs the two panes' folders in one
  step: Update, Mirror (either way) or Two-way, with one confirmation that says what will be copied and deleted. For
  more control, the sync window compares as soon as it opens, sets the direction with one click, and keeps every
  other option one click further down, all of which can be switched:
  - **Saved sync jobs** with one or more folder pairs (this PC ⇄ server or server ⇄ server); a pair can have its own
    settings. More → Sync jobs… lists them: open, run now, duplicate, remove.
  - **A smarter engine.** Two-way remembers the last sync, so deletions carry over instead of coming back, and a file
    changed on both sides is a conflict you decide (or newer / left / right wins). Mirror, Update and Custom (your
    own action for each kind of difference). Compare by time + size (with a tolerance and daylight-saving hour
    shifts), by content (SHA-256) or by size. Include / exclude filters, size and age limits. Every row of the
    preview can be changed, ticked, or excluded from now on.
  - **Versioning instead of deleting.** Deleted and overwritten files go to the Recycle Bin or a versions folder (a
    time stamp per file, a folder per run, or only the last version), pruned after a number of days or versions.
    Permanent deletes on a server need an administrator's approval.
  - **Scheduled and real-time sync:** every N minutes, daily, on chosen weekdays, or a few seconds after a change on
    this PC. Unattended runs leave conflicts alone and stop when a folder is missing (an unplugged disk) or when they
    would delete more than a set share of the files.
  - Jobs and the sync memory are stored encrypted; Settings → Data & backups → Folder sync holds the defaults, and
    every setting is a Group Policy.
