# DarkCipher ServerManagement 0.2.0-preview.2 (2026-10-20)

The second 0.2.0 preview: the results of a full security, performance and interface audit after preview.1
(`docs/history/AUDIT-0.2.0.md`). The installer version is 0.1.22, so it upgrades preview.1 and the final 0.2.0 will upgrade it.

## Security
- **A snapshot restore no longer undoes the AI features lock.** Restoring a snapshot taken before the lock was set used
  to remove the lock and put the old settings back. A restore now never adds, replaces or removes the lock, and while
  the app is locked the restored settings keep the current AI on/off, internet-provider and lock values.
- **Backup "replace everything" can't change what the lock guards.** A backup made (or edited) elsewhere could turn AI
  on; those settings now keep their current values while the lock is set.
- **The error log masks secrets.** Every entry goes through the same masking as everything else before it is written,
  so an exception message holding a request URL with a key never reaches the log.
- **Security analyzers on every build.** The .NET security analyzers run on every build and a finding stops it. They
  found one item in the whole source: the TOTP code's HMAC-SHA1, which RFC 6238 and every authenticator app require.
  It is suppressed next to the line with that reason.

## Interface (same theme, tidier)
- **Tabs stay where they are.** Screens with many tabs (a server's Manage view has 12) no longer move the selected
  row to the bottom; tabs wrap in their own order.
- **Search boxes say what they search** ("Filter hosts…", "Search settings…", "Find in scrollback…") on 14 boxes.
- **Keyboard focus is visible**: text boxes, checkboxes and radio buttons show the accent colour while focused.
- **Long checkbox and radio labels wrap** instead of being cut off at the card's edge.
- **One toolbar on the Hosts screen**: Add host, then Connect / Files / Manage, then Edit / More, with Delete apart at
  the end, all one size on one row.
- **Power actions grouped**: a server's Reboot / Shut down (and a cloud power cycle) sit together at the right of its
  toolbar.
- **Tiles fill the width**: dashboard and server tiles are equal-width columns sized to the window.
- **Sidebar headers** have their section's glyph, a taller click area and a hover highlight.
- **Quick connect's hint** fits the box ("user@host or a saved host").

## Performance
- Start-up is now measured on every self-test run: AI off about 0.76 s and 108 MB, AI on about the same (process start
  to main window, test PC).
- Capability lookups no longer allocate.

## Tests
- The AI-off run now builds every right-click and "More ▾" menu on 26 screens (87 menus) and checks none has an AI
  item.
