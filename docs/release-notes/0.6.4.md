# ServerManagement 0.6.4 (2026-10-22) – DarkCipher Systems

Extra windows for your other monitors, each with its own tabs, split panes and host pane; and Cloud PCs through the
Windows App.

## Added
- **Extra windows for other monitors.** **New window** (Ctrl+Shift+N, or a tab's menu / the pane's ⊞ menu) opens a
  window with its own tabs and its own **host pane** on the left (filter, ⌨ Connect, ＋ Host, ✎ Properties, your folders
  and hosts, ★ Favourites). Put it on another monitor and work there:
  - **Tabs and split panes** like the main window: split right / down, drag tabs between panes and between windows.
  - **Sessions open where you are:** connect from a window's host pane, or open anything while that window is active,
    and it opens in that window. "Switch to the open tab" still finds a host open in any window.
  - **Move tabs** with a tab's menu → **Move to window ▸** (Main window, Window 2…, New window), or drag a tab onto the
    desktop to give it a window of its own there.
  - **The host pane** is pinned open, or 📍 auto-collapses to a slim "Hosts" tab at the window's edge that slides out
    when you point at it (Settings → Navigation → Host pane in extra windows; Group Policy `WindowHostPane`).
  - **Remembered:** the windows come back on their monitors, at their size, the next time the app starts (a window
    whose monitor is gone comes back on the main one). Turn it off in Settings → Navigation (`RestoreWorkspaceWindows`).
  - **Closing a window** that still has tabs asks whether to move them to the main window or close them. A tab you only
    popped out (Ctrl+Alt+O) still closes its window when it goes back.
- **Cloud PCs** (SERVERS → Cloud PCs): Windows 365 Cloud PCs and Azure Virtual Desktop through Microsoft's **Windows
  App**, which can't be embedded, so:
  - **▶ Open the Windows App** starts the installed Windows App (found in the Start menu's list; the Microsoft Store is
    offered when it isn't installed).
  - **🌐 Windows App in a tab** opens Microsoft's Windows App web client in a tab here: every Cloud PC and desktop
    assigned to you, signed in as you, in its own browser profile. No set-up needed.
  - **Your Cloud PCs listed here** (optional): with an app registration in your tenant (Settings → Integrations → Cloud
    PCs, admin approval: the delegated Graph permission CloudPC.Read.All), the page lists them; double-click or
    **Connect in a tab** opens one straight away (Microsoft's direct launch link), or open it in the Windows App.

## Security
- Cloud PCs: Microsoft Graph is used signed in as you (browser sign-in with PKCE; the refresh token in the encrypted
  store; Sign out forgets it), only after you click, and only graph.microsoft.com (a "next page" link elsewhere is
  ignored). Connect links are built here from checked GUIDs. The tenant and app registration are admin-approved
  settings and Group Policies. The web client runs in the app's browser with its own profile (no saved passwords or
  autofill), or your default browser while the app's browser is off.
- Extra windows change nothing about storage or encryption; the window positions are kept in the encrypted settings.
