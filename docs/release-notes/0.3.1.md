# DarkCipher ServerManagement 0.3.1

A small hardening release from the final security and bug check of 0.3.0. No new features.

## Fixed

- **VPN "connect through" now fails closed.** A host that names a VPN profile which no longer exists used to connect
  directly, outside any tunnel. It now refuses with a clear message (pick another profile or clear it in the host's
  settings). Deleting a profile and importing a backup already cleared such references; this closes the last path.
- **Deleting a VPN profile also removes its saved VPN password** (the OpenVPN user name and password credential), which
  was left behind in the vault.
- **"Open in your default browser" in the portal window** only opens http and https addresses (it asked first, but a
  page could have been showing another scheme).

## Checked and found sound

Certificate validation (every callback pins or validates), the Entra id_token verifier (RS256 only, nonce / audience /
issuer / expiry), LDAP over LDAPS or StartTLS, Ansible secrets on stdin only, OpenVPN and WireGuard files removed on
every exit path, OpenVPN's management channel password-protected, archives read in memory only (no extraction), links
from terminals and documents limited to http(s) after a confirmation, no weak random numbers outside retry jitter.
