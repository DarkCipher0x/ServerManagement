# DarkCipher ServerManagement 0.1.7 (2026-10-18)

## Fixed
- **Foundry Local set-up:** a failed model load now shows Foundry's own error message, not just its hint. The full output also goes to the encrypted error log.
- **The AI operator screen frees its memory as soon as you close it.** When the screen opens it checks the AI engine in the background. With a slow or unresponsive engine, a closed screen could stay in memory for several seconds (longer while Foundry Local was answering a status call). The check now lets go of the screen the moment it closes.

## Reliability of the built-in self-test
The self-test that every build must pass is now more trustworthy. Two rare test failures were traced to their real causes and fixed, rather than retried:
- **Add-on flood test:** the test add-on that floods the app with messages was too slow to finish before the add-on's 5-second limit on a busy PC. It now floods at full speed. The app's own protection was always working.
- **AI operator screen memory test:** the fix above. A new test points the AI engine at a server that never answers and checks the closed screen is released within about a second.
- **New timer check:** every screen in the sidebar is opened and closed, and nothing may be left ticking in the background for a closed screen.
- **No silent stops:** a self-test that can't start now always says why, and never shows a message box.

## Before you rely on it
- **Verified by the automated self-test:** 183 checks, no failures, three watched runs.
- **Not code-signed:** SmartScreen shows "unknown publisher", and in-app updates stay switched off.
