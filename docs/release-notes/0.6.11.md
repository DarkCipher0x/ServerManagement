*Built for the launch but never published: 0.6.12 is the public beta release (it adds another AI Engineer fix).*

**Public beta.** Built by an IT engineer, for engineers. Free and open source (MIT).

## A note from the developer
ServerManagement is one of my favourite projects yet, and I'm excited to finally share it. I'm an IT infrastructure
engineer, and I designed it around the job: one encrypted workstation for your servers, network, hypervisors and
clouds, without licences or per-seat pricing. This is just the start. I'll keep adding as many systems as I can, and
all of it stays free and open source.

## Beta: please read
- **This is a beta.** Expect rough edges, and keep backups of anything important (Settings → Data & backups).
- **The installer and the app aren't code-signed yet.** Windows SmartScreen may say "Windows protected your PC": choose
  **More info → Run anyway** only if the SHA-256 of your download matches the one published with the release. The
  update information inside the app *is* signed (ECDSA P-256), and the app refuses updates whose signature doesn't
  match.
- **Testers are very welcome.** Many integrations are built against the vendors' published APIs but haven't yet been run
  against a live account, because I don't have access to those services. If you use any of them, I'd love to hear
  whether it works:
  - Microsoft 365 admin (Intune, Defender, Entra), Windows 365 Cloud PCs and Microsoft Teams;
  - BeyondTrust Privileged Remote Access, Pingdom, Grafana / SIEM links, Elasticsearch and Loki log sinks;
  - Contabo, Hetzner Cloud, Azure and Google Cloud;
  - VMware vCenter, Hyper-V, Proxmox, Unraid, Docker, Puppet, WSL and serial consoles.
- **Bugs and feature requests:** please use the forms on darkciphersystems.com (Report a bug, and Feature requests →
  ServerManagement).

## New
- **Theme packs.** Settings → Appearance → Theme now offers seven built-in packs as preview tiles, each showing its dark
  and light look. **DarkCipher stays the default.** Alongside the DarkCipher packs (DarkCipher, Graphite, Teal, High
  Contrast) there are three everyday ones with their own dark **and** light palettes:
  - **Neutral**: plain greys and a blue accent, like Windows 11.
  - **Slate**: cool blue-grey with an indigo accent.
  - **Arctic**: soft polar greys and frost blue (Nord-style).

  The Mode setting (Follow Windows / Dark / Light) picks the palette. Choosing a pack also brings its own accent, unless
  you picked a different accent yourself. Environment labels (PRODUCTION, TEST, …) look the same under every pack.

## Fixed
- **The AI Engineer now runs the commands small models write as text.** In agent mode with a target terminal, phi-4-mini
  (Foundry Local) wrote its tool calls out as text in a loose form (the tool name twice, "-- session …", headings and
  "[No response …]" lines it made up) instead of calling the tools, so nothing reached the terminal and the made-up
  lines read like results. Those calls now run (with the same approvals and read-only auto-run rules as always); a call
  without a command gets an error that tells the model what to send, so it can correct itself on the next step; and an
  answer that only describes tool calls without making any is flagged in the step log ("nothing ran"). A session id
  written after "-- session" can no longer end up typed as the command. Larger models (e.g. qwen2.5 7B or llama3.1 8B
  in Ollama) call tools natively and are the most reliable choice for agent mode.
- **Typing the server's name to approve now works with Enter.** On a PRODUCTION host the AI Engineer's command review asks
  you to type the host's name. Pressing Enter after typing it hit the dialog's default button, Cancel, so the command
  was reported as declined. Now Enter confirms once the name matches (and does nothing until it does), letter case and
  spaces around the name don't matter, and the box says when it matches. This applies to every typed confirmation in
  the app.
- **The AI Engineer's target terminal defaults to the terminal you're working in.** It no longer starts at "none": it
  follows the terminal in front as you switch tabs, until you pick one yourself (or "none"); "↻ Follow the terminal in
  front" in the dropdown turns that back on. While the AI is working on a task its target stays put, so every step
  goes to the same session.

## Changed
- **The app's name in the title bar, Task Manager and Apps & features** is now "Server Management by DarkCipher
  Systems". The old description ("Vultr and Linux server management") is gone.

## Security
- No change to storage, encryption or network access. The AI Engineer fixes keep every approval: written calls run
  through the same tools, read-only auto-run rules and confirmations as native ones.
- Typed confirmations are still required wherever they were; only Enter and letter case changed (Enter never confirms
  before the name matches, and Esc / Cancel still cancel).
- The default target is only ever the terminal you bring to the front, it never changes during an AI run, and the AI
  still can't switch it without your approval. PRODUCTION targets still review every command.
- Every theme pack is checked by the self-test against the house theme's contrast rules in both modes: body text 7:1,
  secondary text 4.5:1, status colours and accents 3:1.
- A theme pack can be set by Group Policy (`ThemePreset`: darkcipher, graphite, teal, highcontrast, neutral, slate,
  arctic).
