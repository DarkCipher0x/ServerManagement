# DarkCipher ServerManagement 0.1.8 (2026-10-18)

## Foundry Local: hands-off, and it fixes itself
**Turned on by default:** "Set up and repair automatically" (Settings → AI engine). With Foundry Local as the engine, the app now does everything itself, a few seconds after it starts:
- **Installs Foundry Local** if it's missing (Microsoft's package, through winget).
- **Starts the service** if it isn't running.
- **Repairs a service that says it's running but doesn't answer.** This is the problem where every model load failed with "exit 4" until the service was killed and started again by hand. The app now:
  - restarts the service;
  - if that's not enough, stops it completely, ends the stuck Foundry process and starts it fresh.
- **Picks the model build this PC can actually run** (NPU, graphics card or CPU; x64 or ARM). A model chosen on another PC no longer fails on this one.
- **Downloads and loads the model.** If loading fails, it repairs the service and tries once more.
- **Repairs mid-question:** if an AI question finds Foundry Local not answering, the same repair runs once and the question is asked again.

**Every step is visible:**
- the status bar and the new STATUS lines in Settings show what's happening;
- installs, downloads and repairs are in the audit log;
- errors show Foundry Local's own message, not just its "Hint".

**Limits:**
- offline mode never installs or downloads;
- on battery, a model over 1 GB waits for mains power unless you press "Set up now".

**Buttons for every step:** Set up now, Restart service, Stop service, Unload model, Show log, Copy the commands, plus Test.

## Clearer model choice
- **"Show the models for this PC"** lists what Foundry Local offers on *this* machine, grouped NPU / GPU / CPU. Each model shows:
  - its size;
  - whether it's downloaded;
  - whether it can use tools (the AI operator needs this);
  - a line on what it's good for.
- **The recommendation for this PC is on top, with the reason.** For example, on a PC with a 16 GB graphics card it recommends qwen2.5-7b on the GPU.
- **"Use"** switches to a model and loads it.
- **The default model is now a model name** (phi-4-mini, qwen2.5-1.5b or qwen2.5-0.5b) rather than a CPU-only build. Each PC runs its best build of it: a PC with a strong graphics card now uses it automatically.

## Also in this version

## Before you rely on it
- **Verified by the automated self-test** (189 checks, no failures). It runs a scripted Foundry Local through the worst case: not installed, a service that doesn't answer, a model from another PC, and a load failing with exit 4. The app's parsing is checked against real Foundry Local 0.11 output from this PC.
- **Not yet tried on your Copilot+ PC:** the NPU path is tested with a synthetic catalogue.
