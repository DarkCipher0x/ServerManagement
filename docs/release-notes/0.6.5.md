# ServerManagement 0.6.5 (2026-10-22) – DarkCipher Systems

Restart, rename and power actions for Cloud PCs.

## Added
- **Cloud PC actions** on each Cloud PC listed on the Cloud PCs page (with an app registration):
  - **⟳ Restart** your Cloud PC, and **✎ Rename…** it.
  - **Admin ▾** (Windows 365 / Intune administrators): **Troubleshoot** (Microsoft's health check of the Cloud PC and
    its session host), and for Windows 365 Frontline Cloud PCs **Power on** and **Power off** (power off deallocates it
    and revokes its licence immediately, so it asks you to type the name).

  Each asks first and is written to the audit log, whatever the result. They are off until you turn them on in
  Settings → Integrations → Cloud PCs (admin approval; Group Policy `CloudPcAllowActions`).

## Security
- The actions need the Microsoft Graph permission CloudPC.ReadWrite.All. It is asked for in a **separate sign-in**, only
  when you first use an action, so the read-only list never holds write rights; Sign out forgets both.
- Addresses are Microsoft's documented action paths, built here from checked Cloud PC ids (a new name: 1–64 characters,
  no control characters); only graph.microsoft.com is contacted. Restart and rename of your own Cloud PC use Microsoft
  Graph beta (the only place Microsoft offers them to a non-administrator).
