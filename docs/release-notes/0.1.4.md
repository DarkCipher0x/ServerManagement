# DarkCipher ServerManagement 0.1.4 (2026-10-18)

## New: crash recovery ("Recover previous work")
If the app didn't close cleanly (a crash, a power cut, Windows killing it), the next start shows one screen with a box for everything it can bring back. Nothing connects, nothing is written to a server and no transfer starts unless you tick it.
- **Open tabs:** terminal, Files, Manage and Remote Desktop tabs come back where they were: same panes, pop-out windows, tab groups and active tab.
  - They always reopen **disconnected**.
  - Remote Desktop tabs and the layout are new; before, only the tabs themselves came back, in one pane.
- **Unsaved edits:** text you were editing in a remote file reopens in the editor, marked "recovered — not saved yet". Nothing is written until you press Save.
  - If the file changed on the server since you started, you're asked before it's overwritten.
- **Unfinished transfers:** copies and moves are queued again, and unfinished files resume from their ".dcxpart" part.
  - A folder sync's deletions are never repeated after a crash: run the sync again to mirror.
- **Your choices:** **Recover selected** brings back what's ticked and discards the rest. **Later** keeps everything and asks at the next start. **Discard all** asks first when edits would be lost.

## Fixed
- **Unsaved remote-file edits were lost when you exited the app or Windows logged off with an editor still open.** They're now kept and offered at the next start.
- **Notes and incident edits are saved at once if the app hits a fatal error.** Before, they only saved about a second after you stopped typing.

## How it's kept
- **Encrypted, like everything else:** unsaved text and the transfer list live in an encrypted recovery file (`recovery.dcx`).
- **When it's written:** about 2 seconds after a change, and at once on a fatal error, when Windows shuts down and when you exit. Nothing is written while nothing changes. The file is deleted when there's nothing to recover.
- **Limits:**
  - A sudden power cut can lose the last couple of seconds of typing.
  - Very large drafts (over 2 million characters) aren't kept.
  - AI conversations and half-filled dialogs aren't recovered.

## Before you rely on it
- **Verified by the automated self-test** (173 checks, no failures, two watched runs). One test crashes for real: a separate copy of the app is killed mid-work with an unsaved draft, a paused transfer and its tabs, and the next run must recover all three.
- **Not code-signed:** SmartScreen shows "unknown publisher", and in-app updates stay switched off.
