# ServerManagement 0.5.4 (2026-10-21) – DarkCipher Systems

A fix release from DarkCipher0x's testing of 0.5.3.

## Fixed
- **A right-click left the mouse "locked into" the pane.** After a right-click in LOGS → Error log, the pane kept hold of
  the mouse: its own buttons (Refresh, Open folder, Copy) still worked and freed it, but the sidebar and every other
  screen ignored clicks. The mouse is now let go as soon as every button is up, unless a menu, an open drop-down or a
  popup is using it, as they do to close when you click elsewhere. If anything holds on again, the app releases it and
  names the control in LOGS → Error log ("Mouse capture released"). A self-test checks it on every build.

## Security
- No change to storage, encryption, network access or policies. The new log entry records control types only, never
  text.
