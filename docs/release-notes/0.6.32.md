## Beta: please read
- **This is a beta.** Expect rough edges, and keep backups of anything important (Settings → Data & backups).
- **The installer and the app aren't code-signed yet.** Windows SmartScreen may say "Windows protected your PC": choose
  **More info → Run anyway** only if the SHA-256 of your download matches the one published with the release. The
  update information inside the app *is* signed, twice (ECDSA P-256 and post-quantum ML-DSA-65), and the app refuses an
  update unless both signatures match.
- **Testers are very welcome.** Many integrations are built against the vendors' published APIs but haven't yet been run
  against a live account, because I don't have access to those services. If you use any of them, I'd love to hear
  whether it works:
  - Microsoft 365 admin (Intune, Defender, Entra), Windows 365 Cloud PCs and Microsoft Teams;
  - Bitwarden (Password Manager and Secrets Manager, cloud and self-hosted / Vaultwarden);
  - UniFi (Network on a console or through the Cloud Connector, and Site Manager);
  - BeyondTrust Privileged Remote Access, Pingdom, Grafana / SIEM links, Elasticsearch and Loki log sinks;
  - Contabo, Hetzner Cloud, Azure and Google Cloud;
  - VMware vCenter, Hyper-V, Proxmox, Unraid, Docker, Puppet, WSL and serial consoles.
- **Bugs and feature requests:** please use the forms on darkciphersystems.com (Report a bug, and Feature requests →
  ServerManagement).

## Faster start, lighter process
A start-up pass with a new built-in timeline (ADR-110). On the same PC, process start to the first frame of the main
window went from about 800 ms to about 650 ms with AI features off, and from about 1,170 ms to about 680 ms with
them on; the window is idle about 100 ms later.
- **Compiled ahead of time.** The app's own code and the libraries a session uses ship compiled (ReadyToRun), so a
  start no longer compiles them. The installer grows by about 7 MB for it.
- **The encrypted store opens in parallel.** The data key is unwrapped on a worker thread while the window's theme and
  fonts are set up, and the JSON metadata for your settings and data is built ahead of time, so the start-up check
  of every store file no longer waits for it.
- **Nothing loads before it's needed.** WinForms (only the embedded Remote Desktop control and the tray balloon use
  it), the AI sidebar's HTTP client and the Foundry Local check used to load or run before the first frame; they
  don't now. Three terminal filters that compiled their patterns at start-up are built at compile time instead,
  and so are those of the first terminal tab.
- **Old terminal pages are cleared.** Every version unpacks its terminal page into the cache; the folders of earlier
  versions are removed at the first start.
- **For developers:** `DCX_STARTUP_TRACE=<file>` writes the start-up timeline (each phase's time, memory and the
  assemblies it loaded); `DCX_STARTUP_TRACE_STACKS=1` adds the call stack behind every assembly load. See
  docs/BUILD.md.
