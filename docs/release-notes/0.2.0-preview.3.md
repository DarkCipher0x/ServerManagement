# DarkCipher ServerManagement 0.2.0-preview.3 (2026-10-20)

Everything in preview.2, plus two changes you asked for. The installer version is 0.1.23, so it upgrades preview.2 and
the final 0.2.0 will upgrade it.

## New

### TEAM in the sidebar
- While a shared library add-on is enabled, the sidebar has a **TEAM** section:
  - **Shared library**: members, join requests, collections, sync, the shared audit.
  - **Team hosts**: Hosts, opened on the library's node.
  - **Team credentials**: Credentials with the new **⇄ Shared only** filter ticked. VAULT → Credentials still shows
    everything.
- The section goes away when the add-on is disabled. It can be moved or hidden like any other section.

### A more capable Cloud providers tree (the "recent" buttons are gone)
- **★ Pinned:** right-click any screen → **Pin to top** keeps it in a Pinned branch at the top of the tree. Only what
  you pin is there (up to 20, kept in the encrypted settings); right-click → Unpin removes it.
- **Right-click acts on what you clicked**, not on whatever was selected before:
  - a screen: Open, Open in its own tab, Pin / Unpin;
  - a provider: open its main screen, expand or collapse all of it, **Switch account**, its account settings.
- **Ctrl+Enter or a middle click** opens a screen in its own tab.
- **Arrow keys move without loading:** walking the tree with the keyboard no longer opens (and loads) every screen on
  the way; Enter or a click opens.
- Search: Esc clears it, ↓ moves into the tree.
- Provider names no longer repeat an account named like the provider ("Vultr", not "Vultr · Vultr"), and show how
  many accounts there are when there is more than one.
- Settings → Navigation & explorers: "Clear the recent list" became "Unpin every Cloud providers screen". The old
  recent list in your settings is simply ignored.
