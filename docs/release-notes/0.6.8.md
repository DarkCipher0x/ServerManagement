# ServerManagement 0.6.8 (2026-10-23) – DarkCipher Systems

The Hosts page's tree is now a full host pane.

## Fixed
- **Folders in the Hosts pane expand to show their hosts.** The tree beside your sessions only listed folders, so a
  folder like "General (2)" had nothing to open, and with a terminal in front you couldn't reach those hosts. Now the
  pane (headed **HOSTS**) is a complete host pane:
  - **Hosts sit inside their folders** (and under the Platform / Protocol / Tags / Jump host views, Favourites and
    shared collections). **Double-click** or **Enter** connects, inside the Hosts tab.
  - **Right-click a host** for its full menu, the same as in the list (connect, new connection, files, manage, edit,
    favourites, notes, move…). Right-click a folder for the folder's menu, as before.
  - **Drag a host** onto another folder (or onto a host in it) to move it there.
  - **Filter hosts…** at the top narrows the tree to matching hosts and the folders holding them.
  - **＋ Host** (next to ＋ Folder) adds a host to the selected folder.
  - Selecting a host also selects it on the All hosts tab. A folder behind a closed lock shows nothing inside until you
    expand it and unlock; a locked host shows its padlock and no address.

## Security
- No change to storage, encryption or network access. Locks hide hosts in the tree exactly as in the list.
