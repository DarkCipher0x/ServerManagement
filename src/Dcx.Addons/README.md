# Dcx.Addons

Add-ons: package inspection, install, verification and sealed data files, the data add-on kinds features register (`AddonPackages.RegisterKind`), the Low-integrity sandbox and job, the encrypted bridge (API 2), the add-on host and its method table (`app.call` goes through the capability registry), theme add-ons.

May reference: Dcx.Core, Dcx.Connectivity, Dcx.Ui. The shared library and the portal browser sit above it.
