# Dcx.Infra

Infrastructure engines: Docker (over SSH or the local pipe), Proxmox, Unraid, VMware vCenter and Hyper-V (WinRM / CIM) — inventory, capabilities discovered from the target, actions with verified results, TLS pinning, the status the dashboard reads.

May reference: Dcx.Core, Dcx.Connectivity. No WPF (the Infrastructure screen is in the app).
