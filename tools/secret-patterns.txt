# Secret patterns for tools\secret-scan.ps1 (release pipeline). One rule per line: name<TAB>regex (.NET syntax).
# The scan runs over everything about to be published (the staged public tree, and later the website output) and
# aborts the publish on any match. These rules add this project's own formats to gitleaks' (when gitleaks is present).
# A line that must contain a pattern-shaped example (a test fixture) carries the marker  secret-scan: example
# on the same line; nothing else is ever skipped.
Discord webhook URL	(?i)https://(?:ptb\.|canary\.)?discord(?:app)?\.com/api/webhooks/\d{5,}/[A-Za-z0-9_\-]{20,}
GitHub token	\b(?:ghp|gho|ghu|ghs|ghr)_[A-Za-z0-9]{36,}\b
GitHub fine-grained token	\bgithub_pat_[A-Za-z0-9_]{50,}\b
Private key block	-----BEGIN (?:RSA |EC |DSA |OPENSSH |PGP |ENCRYPTED )?PRIVATE KEY(?: BLOCK)?-----
PuTTY private key	PuTTY-User-Key-File-\d:
OpenAI or Anthropic key	\bsk-(?:ant-)?[A-Za-z0-9_\-]{32,}\b
Slack token	\bxox[abprs]-[A-Za-z0-9\-]{10,}\b
AWS access key	\b(?:AKIA|ASIA)[0-9A-Z]{16}\b
Google API key	\bAIza[0-9A-Za-z_\-]{35}\b
Azure storage key	(?i)AccountKey=[A-Za-z0-9+/]{80,}={0,2}
Telegram bot token	\b\d{8,10}:AA[A-Za-z0-9_\-]{33}\b
Grafana service token	\bglsa_[A-Za-z0-9_]{32,}\b
Credentials in a URL	(?i)\b(?:https?|ftp|ssh|sftp)://[A-Za-z0-9._%\-]+:[^@\s/'"<>]{3,}@[A-Za-z0-9.\-]+
